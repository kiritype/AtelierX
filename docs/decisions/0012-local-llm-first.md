# 0012. LLM은 로컬을 기본으로 하고, 미리 만든 프롬프트 규칙은 가이드라인으로 둔다

- 날짜: 2026-10-02
- 상태: 채택

## 결정

- 기본 LLM 연결은 로컬 OpenAI 호환 서버 하나다. 모든 작업이 기본으로 이 연결을 쓴다. 연결 방식은 OpenAI 호환 하나로 시작한다.
- 외부 서비스는 사용자가 직접 추가했을 때만 쓴다. 작품 내용을 외부로 처음 보낼 때 작품 × 연결 단위로 확인을 받는다.
- 압축 규칙, JSX 사용 규칙처럼 LLM 작업에 쓸 프롬프트 규칙은 가이드라인으로 만든다. 공통 규칙은 전역에, 플랫폼마다 다른
  규칙은 플랫폼 프리셋에, 작품만의 규칙은 작품에 같은 이름으로 둔다.

## 이유

- 챗봇 원고는 공개 전 창작물이고 외부 서비스의 이용 정책에 걸릴 수 있는 내용도 있다. 기본값이 로컬이면 의도하지 않은 외부
  전송이 생기지 않는다.
- 로컬 서버(LM Studio, llama.cpp, vLLM 등)와 많은 외부 서비스가 OpenAI 호환 형식을 지원하므로 방식 하나로 대부분을 다룬다.
- 프롬프트 규칙을 가이드라인으로 두면 이미 있는 덮어쓰기 구조(전역 → 플랫폼 프리셋 → 작품)를 그대로 쓸 수 있다. 앱은 출력
  형식만 지키고, 내용 지침은 사용자가 고친다.

## 결과

- 형식은 data-model.md의 "LLM 연결"과 "가이드라인 — 정해진 이름" 절, 동작은 features/03-llm.md.
- 모델 가격은 사용자가 입력하며, 없으면 토큰 수만 보여 준다.
