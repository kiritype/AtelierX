# 0010. 설정·데이터·출력은 모두 앱 폴더 안에 둔다

- 날짜: 2026-10-02
- 상태: 채택

## 결정

프로그램(`app/`), 설정(`config/`), 상태(`state/`), 데이터(`data/`), 출력(`output/`)을 모두 앱 폴더 하나 안에 둔다.
사용자 프로필 폴더(`%APPDATA%`, `문서` 등)에는 쓰지 않는다.

## 이유

- 앱 폴더를 통째로 복사하면 백업·이동·다른 PC 사용이 끝난다.
- 앱과 그 데이터가 어디 있는지 사용자가 한눈에 안다.

## 결과

- 업데이트는 `app/`만 교체한다. 나머지 폴더는 건드리지 않는다.
- 설정 안의 경로는 앱 폴더 기준 상대 경로로 적는다. 앱 밖을 가리키는 것은 LoRA 폴더(이미지 생성 도구와 공유할 때)뿐이다.
- 인증 정보는 마스터 비밀번호로 암호화한 `config/vault.json`에 둔다. OS에 의존하지 않으므로 다른 PC로 옮겨도 비밀번호만
  알면 열린다([0011](0011-master-password-vault.md)).
- 앱 폴더는 쓰기 가능한 위치에 둬야 하므로, 배포는 쓰기 제한 폴더(`Program Files` 등)에 설치하는 방식이 아니라
  사용자가 고른 폴더에 풀거나 설치하는 방식으로 한다.
