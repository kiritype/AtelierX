# 0018. 이미지 모듈은 기존 이미지 도구의 기능과 소스를 가져와 AtelierX 구조에 맞춘다

- 날짜: 2026-10-03
- 상태: 채택
- 대체함: [0001](0001-independent-project.md)의 "다른 도구의 코드에 의존하지 않고 새로 설계한다" 중 이미지 모듈 부분

## 결정

- 이미지 모듈(라이브러리, 생성·대기열, 생성·비교, 갤러리·검수와 자동 검수, 이미지 도구, LoRA 데이터셋·학습·적용, 이미지 생성
  서버 연결·GPU 관리)은 같은 작성자의 기존 이미지 도구(MIT)가 가진 기능을 모두 가져온다. 소스도 가져와 고쳐 쓸 수 있다.
- 데이터 구조와 화면 흐름은 AtelierX 기준이다. 캐릭터는 캐릭터 항목(ID)에서 출발하고, 이미지 프롬프트 재료는 `design.json`과
  이미지 라이브러리(data-model "이미지 데이터")를 쓴다. 가져온 코드는 이 구조에 맞게 고친다. 기존 도구의 파일 형식과 호환하지 않는다.
- 이미지 기능은 작품 창 상단 메뉴 막대의 **이미지** 메뉴에서 연다.

## 이유

- 이미 검증된 기능(이미지 생성 서버 워크플로, 대기열, 검수, 이미지 도구, LoRA 학습 연동)을 다시 만드는 비용이 크다.
- 데이터는 작품·캐릭터 중심으로 하나로 두어야 글과 이미지가 같은 곳에서 출발한다(0001의 이유는 그대로 유효).

## 결과

- 가져온 코드의 출처와 제3자 구성 요소는 `THIRD_PARTY_NOTICES.md`에 적는다. 런타임에만 쓰는 GPL·AGPL 구성 요소(이미지 생성 서버,
  확장 노드, 검출 모델 라이브러리)는 함께 배포하지 않고 설치 안내만 한다.
- 이미지 생성 서버용 확장 노드는 AtelierX 저장소의 별도 폴더로 두고, 앱이 설치를 돕는다.
- 처음 지원하는 모델 계열은 anima와 SDXL(Illustrious·NoobAI·Pony 포함), LoRA 학습 도구는 anima 전용 학습 도구다.
