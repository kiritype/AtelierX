# 0008. 파일 트리 = 디스크 = 내보내기, 참조는 ID로 한다

- 날짜: 2026-10-02
- 상태: 채택 (일부를 [0015](0015-start-situation.md), [0017](0017-test-screen.md)이 대체함)

## 결정

- 편집 화면은 텍스트 편집기처럼 왼쪽에 파일 트리를 둔다. 트리는 작품 폴더(`.atelierx/` 제외)의 디스크 구조와 같고,
  내보내기도 같은 경로·이름의 파일로 한다(항목마다 파일 하나).
- 작품 폴더와 그 안의 파일·폴더 이름은 사용자가 정하고, 그 이름이 표시 이름이다. 메타데이터에 이름 필드를 따로 두지 않는다.
- 작품과 항목은 바뀌지 않는 ID를 가진다. 편집기 상단 폼에서 입력하며, 종류에 맞는 `W001`·`M001`·`G001`·`L001`·`C001`·`J001`
  형식의 다음 번호를 placeholder로 권유하고 비워 두면 그 값을 쓴다.
- 관계 표, 시나리오, 이미지 데이터, JSX 예시 props, 출력 경로, LoRA 파일 이름은 모두 ID로 가리키거나 ID로 만든다.

## 이유

- 보이는 것과 저장된 것과 내보내는 것이 같으면 사용자가 결과를 예측하기 쉽다.
- 이름은 자주 바뀌고 ID는 바뀌지 않는다. 둘을 나누면 이름을 바꾸거나 파일을 옮겨도 연결이 끊어지지 않는다.
- 이름과 ID가 각각 한 곳에만 있어 어긋날 일이 없다.

## 결과

- 형식은 data-model.md의 "작품 폴더", "항목", "ID", "내보내기" 절.
- 내보내기에서는 메모와 사용하지 않는 항목을 뺀다.
- ID 바꾸기는 영향 범위를 보여 주고 확인을 받은 뒤 스냅샷과 함께 한꺼번에 처리한다.
- ID는 영문·숫자·`_`·`-`만 쓴다(폴더·파일 이름에 쓰이므로).
