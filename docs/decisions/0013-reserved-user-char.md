# 0013. 사용자와 대화 상대는 `{{user}}`, `{{char}}`로 고정한다

- 날짜: 2026-10-03
- 상태: 채택

## 결정

챗봇을 쓰는 사람은 `{{user}}`, 1:1 작품(`scale: single`)에서 사용자가 대화하는 상대 캐릭터는 `{{char}}`로 쓴다. 둘은 항목 ID가
아닌 예약 참조이며, 본문·첫 메시지·키워드·관계 표에서 쓸 수 있다. `{{char}}`가 가리키는 캐릭터는 `work.json`의 `char`로 정한다.

## 이유

- 챗봇 플랫폼에서 널리 쓰는 표기라, 내보낸 글을 그대로 붙여 넣어도 플랫폼이 실제 이름으로 바꾼다.
- 관계 표에 캐릭터 → 사용자 관계·호칭을 적을 곳이 필요했다.

## 결과

- 내보내기는 예약 참조를 그대로 둔다. 대화 테스트만 페르소나 이름과 캐릭터 이름으로 바꿔 보낸다.
- 예약 참조 바로 뒤에 조사를 붙이지 않도록 권하고, 규칙 검사가 알린다.
- 형식은 data-model.md의 "예약 참조" 절.
