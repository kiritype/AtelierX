# 0006. 작품 폴더 구조는 자유로 두고, 항목의 종류는 메타데이터로 정한다

- 날짜: 2026-10-02
- 상태: 채택 (일부를 [0015](0015-start-situation.md), [0017](0017-test-screen.md)이 대체함)

## 결정

- 작품 폴더 안의 폴더 구조와 파일 이름은 사용자가 정한다. 앱은 고정 폴더(메인 프롬프트 파일, 로어북 폴더, JSX 폴더 등)를
  두지 않고, 기본 폴더도 만들지 않는다.
- 파일을 만드는 방법은 하나("새 파일")이고, 종류(메인 프롬프트, 첫 메시지, 로어북, 캐릭터, JSX, 메모)는 만든 뒤 편집기 상단 폼에서
  고른다. 종류는 파일의 메타데이터(`kind`)에 저장한다.
- 앱이 관리하는 데이터(작품 설정, 관계 표, 이미지 데이터, 시나리오, 임시 항목, 휴지통, 이력)는 작품마다 `.atelierx/` 폴더
  하나에 모은다.

## 이유

- 분류와 배치는 정리용이고 플랫폼·작품마다 다르다. 같은 Markdown 파일이 메인 프롬프트·로어북·메모 어느 것도 될 수 있으므로
  만드는 방법을 나눌 이유가 없다.
- 동작이 위치가 아니라 메타데이터로 정해지면 파일을 옮겨도 동작이 바뀌지 않는다.
- 앱 데이터를 한 폴더에 모으면 사용자 트리와 이름이 부딪히지 않고, 트리에는 사용자의 글과 코드만 보인다.

## 결과

- 권장 구성은 배포에 포함하는 샘플 작품으로 보여 준다. 앱은 새 파일에 섹션 뼈대 등을 자동으로 넣지 않는다.
- 종류별 부가 데이터(캐릭터 이미지 데이터, JSX 예시 props)는 `.atelierx/` 아래 ID 기반 폴더에 두고 ID로 연결한다.
- 같은 내용의 여러 판(원본과 압축본 등)을 함께 둘 수 있도록 항목마다 사용 여부(`enabled`)를 둔다. 메인 프롬프트는 여러 개
  둘 수 있지만 사용 중인 것은 하나다.
- 형식은 data-model.md의 "작품 폴더"와 "항목" 절.
