# 0007. 큰 파일은 출력 루트에 두고 상대 경로와 해시로 연결한다

- 날짜: 2026-10-02
- 상태: 채택

## 결정

생성 이미지·학습 로그 같은 큰 파일은 데이터 루트(`data/`) 밖의 출력 루트(`output/`)에 둔다. LoRA 파일은 LoRA 폴더(기본 `output/loras/`)에 둔다.
작품 폴더에서 이 파일들을 가리킬 때는 루트 기준 상대 경로, sha256, 크기만 담은 참조를 쓴다.

## 이유

- 작품 데이터만 따로 백업·공유할 때 큰 파일이 섞이면 무거워진다.
- 스냅샷이 큰 파일을 복사하지 않고 참조만 기록할 수 있다.
- 절대 경로를 쓰지 않으면 루트를 옮겨도 연결이 유지되고, 해시로 같은 파일인지 확인할 수 있다.

## 결과

- 형식은 data-model.md의 "큰 파일"과 "이미지 데이터" 절.
- 배포 표시된 스냅샷이 참조하는 파일은 자동 정리에서 지우지 않는다.
