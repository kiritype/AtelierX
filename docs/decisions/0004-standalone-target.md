# 0004. 스탠드얼론 배포를 전제로 설계한다

- 날짜: 2026-10-02
- 상태: 채택

## 결정

개발은 로컬 웹 서버 + 브라우저로 하되, 최종 배포는 데스크톱 프로그램을 목표로 한다.
화면은 빌드 단계(Vite)를 둔다.

## 결과

- 화면은 빌드한 정적 파일을 Python 서버가 제공한다. 데스크톱 창(pywebview 또는 Tauri)은 이 서버를 띄워 보여 준다.
- 포트는 자동으로 고른다.
- 설정·데이터·출력은 앱 폴더 안에 둔다([0010](0010-portable-app-folder.md)).
- 파일 선택·알림 등 데스크톱 기능은 추상화해 브라우저에서는 대체 화면을 쓴다.
- 데스크톱 셸 선택(pywebview / Tauri)은 architecture.md에서 정한다.
