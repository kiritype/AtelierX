# 0001. 독립 프로젝트로 새로 구축한다

- 날짜: 2026-10-02
- 상태: 채택 (이미지 모듈의 "새로 설계" 부분은 [0018](0018-image-module-port.md)이 대체함)

## 결정

RP 챗봇 제작(메인 프롬프트, 로어북, JSX, 대화 테스트)과 캐릭터 이미지 기능(이미지 프롬프트, 생성, 검수, 데이터셋,
LoRA 학습)을 한 프로그램에서 다룬다. 다른 도구의 코드나 데이터 형식에 의존하지 않고 새로 설계한다.

## 이유

- 데이터 구조를 작품·캐릭터 중심으로 하나로 맞출 수 있다. 캐릭터의 글과 이미지 정의가 같은 곳에서 출발한다.
- 외부 형식에 맞추느라 생기는 중복(같은 이름·코드를 두 파일에 적는 것 등)과 변환 단계가 없다.

## 결과

- 이미지 기능은 단계적으로 만든다. 먼저 외모·의상 → 이미지 프롬프트, 그다음 생성·검수·데이터셋·LoRA 학습.
- 이미지 데이터 형식은 data-model.md에서 다른 데이터와 같은 원칙으로 정의한다.
