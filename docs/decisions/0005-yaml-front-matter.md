# 0005. 로어북 메타데이터는 YAML 앞부분 메타데이터로 둔다

- 날짜: 2026-10-02
- 상태: 채택

## 결정

항목(`.md` 파일)의 메타데이터는 본문 앞의 YAML 메타데이터(front matter)에 둔다. 옆에 JSON 파일을
따로 두지 않는다.

## 이유

- 본문과 메타데이터가 한 파일에 있으면 이름 변경·복제·스냅샷 비교·다른 편집기 사용이 단순하다.
- 파일을 둘로 나누면 한쪽만 옮겨지거나 지워지는 불일치가 생긴다.

## 결과

- 읽을 때는 표준 YAML로 읽는다. 앱이 쓸 때는 문자열·숫자·참/거짓·목록만 쓴다.
- 다시 쓸 때 키 순서와 모르는 필드를 보존한다(순서를 보존하는 YAML 라이브러리를 쓴다).
- `.jsx` 항목은 YAML 머리를 둘 수 없으므로 파일 맨 앞 주석 블록(`/*--- … ---*/`)에 같은 형식으로 둔다.
