# 0009. 플랫폼 규칙은 플랫폼 프리셋으로 만들고 작품에 태그로 연결한다

- 날짜: 2026-10-02
- 상태: 채택

## 결정

용량 제한, 세는 방식, 로어북 활성화, JSX 규칙 같은 플랫폼 규칙은 설정 화면에서 **플랫폼 프리셋**으로 만든다.
작품은 태그로 프리셋에 연결되어 값을 상속받고, 작품에서만 다른 값은 `work.json`의 `overrides`에 적는다.

## 이유

- 같은 플랫폼용 작품 여럿이 규칙을 한 곳에서 공유한다. 플랫폼 규칙이 바뀌면 프리셋 하나만 고치면 된다.
- 태그는 작품 분류에도 쓰이므로, 연결을 별도 필드가 아니라 태그로 하면 개념이 하나 줄어든다.

## 결과

- 상속 순서: 앱 기본값 → 연결된 프리셋들(`tags` 순서) → 작품 `overrides`. 화면에서 값의 출처를 보여 준다.
- 설정에서 "기본 플랫폼 프리셋"을 지정하면 새 작품에 그 태그가 붙는다. 지정하지 않으면 새 작품은 연결되지 않는다.
- 프리셋에 들어갈 항목은 기능 설계를 진행하며 채운다. 형식은 data-model.md의 "플랫폼 프리셋" 절.
