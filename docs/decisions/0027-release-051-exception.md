# 0027. 이미지 제작 흐름과 테마 개선을 이번에 한해 0.5.1로 낸다

- 날짜: 2026-11-10
- 상태: 채택
- 관련: [0022 버전 정책](0022-versioning.md), [0020 브랜치 흐름](0020-branch-flow.md)

## 결정

사용자가 지정한 이번 릴리스 번호는 **0.5.1**이다. 새 기능과 저장 형식 변경을 포함하므로 0022의 일반 기준과 다르지만,
이번 릴리스에 한해서 예외를 적용한다. 일반 버전 정책을 바꾸거나 보류한 0.6.0 작업을 다시 포함하지 않는다.

범위는 색상·버튼(#313), 생성 화면·집중 모드(#314), 공통 구도 선택기(#315), 그림체·프롬프트 출처(#316),
결과 요약·복원·재생성(#317), 테마 선택(#319)과 그 흐름의 갤러리 조회 개선이다.
작품 텍스트 번역(#318·#57), MOSS(#307), 다중 캐릭터와 기존 보류 항목은 포함하지 않는다.

## 데이터 호환과 검증

- 설정은 이전 형식을 읽고 테마가 없으면 시스템 설정을 따른다. 설정을 저장할 때 `schema_version` 2와 테마를 기록한다.
  기존 언어·자동 저장 등 설정은 유지한다. 이전 파일은 조회만으로 다시 쓰지 않는다.
- 생성 결과에는 출처를 보존하는 기록 형식이 추가된다. 예전 기록의 읽기·설정 복원과 새 기록의 재생성을 함께 검증한다.
- 기존 작품, UUID 참조, 이미지 경로와 원본 파일을 보존한다. 0.5.0 합성 데이터의 별도 복사본으로 Windows 패키지 업데이트를 검증한다.
- 구도 선택은 기본 자동 상태에서 선택적으로 사용하며 BETA로 표시한다. 프롬프트를 통한 지시이므로 모델마다 반영 정도가 다르다.

## 출시 조건

버전 표기·잠금 파일을 동기화하고 전체 회귀 검사, 오프라인 설명서 검사, Windows 패키지 실행 및 업데이트 보존 검증을 마친다.
확인 결과와 남은 제약은 [검증 범위](../manual/guide/release-status.md)에 기록한다.
로컬 검증 완료와 공개 RC·정식 릴리스는 구분하며, 공개 절차는 0020을 따른다.
