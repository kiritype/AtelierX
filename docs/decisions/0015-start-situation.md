# 0015. 첫 메시지(인사말)를 "시작 상황"으로 부르고 여러 개를 둔다

- 날짜: 2026-10-03
- 상태: 채택
- 대체함: [0006](0006-free-work-folder.md)의 종류 이름 "첫 메시지", [0008](0008-tree-is-disk.md)의 ID 권유 형식 `G001`

## 결정

- 대화가 시작되는 장면 항목을 "시작 상황"이라 부른다. 종류 값은 `start`, ID 권유 형식은 `S001`이다.
- 한 작품에 시작 상황을 여러 개 둘 수 있고, 사용 중인 것이 여럿이어도 된다.

## 이유

- 플랫폼에서는 첫 메시지 한 줄보다 장면과 상황 설명을 함께 주는 경우가 많고, 사용자가 여러 시작 중 하나를 고른다.
- "인사말"은 1:1 대화의 첫인사로만 읽혀 다인·시뮬레이션 작품에 맞지 않는다.

## 결과

- 종류 목록은 `main`·`start`·`lorebook`·`character`·`jsx`·`note`.
- 시나리오의 시작 지정 필드도 `start`다. 대화 테스트는 사용 중인 시작 상황 중 하나를 고른다.
- 개발 중 만든 `kind: greeting` 항목은 `start`로 읽는다.
