# 0003. 리비전은 자체 스냅샷 저장소로 관리한다

- 날짜: 2026-10-02
- 상태: 채택

## 결정

작품마다 `.atelierx/history/`에 내용 해시 기반 스냅샷을 저장한다. git은 쓰지 않는다.

## 이유

- 작품 폴더가 사용자의 git 저장소 안에 있을 수 있어서, 앱이 자동 커밋하면 사용자의 이력과 섞인다.
- git 설치 여부와 관계없이 동작해야 한다(스탠드얼론 배포).

## 결과

- 형식은 data-model.md의 "스냅샷" 절.
- 사용자가 따로 git을 쓰는 것은 막지 않는다. `.atelierx/history/`를 git에서 제외하도록 안내한다.
