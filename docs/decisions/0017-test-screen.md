# 0017. 대화 시나리오를 없애고 테스트 화면으로 합친다

- 날짜: 2026-10-03
- 상태: 채택
- 대체함: [0006](0006-free-work-folder.md)·[0008](0008-tree-is-disk.md)에 적힌 앱 데이터 "시나리오"

## 결정

- 대화 시나리오(대화를 저장해 두고 턴마다 기대값으로 채점·비교하는 기능)를 두지 않는다.
- 보조 패널의 채팅 테스트를 빼고, 상단 바의 **테스트** 버튼으로 여는 별도의 테스트 화면을 둔다. 설정에서 정한 LLM으로 돌린다.
- 테스트 화면은 챗봇 구성 그대로 동작한다: 시작 상황(슬라이드로 고름), 메인 프롬프트(항상 불러옴), 로어북(활성화 키워드로
  불러옴), JSX(응답에서 호출하면 표시). 턴마다 불러온 내용을 옆에 보여 준다.
- 원고를 고친 뒤 같은 입력으로 다시 확인하는 용도로 "입력 다시 보내기"만 둔다.

## 이유

- 로어북 활성화는 플랫폼마다 고유한 기능이라, 앱이 흉내 낸 규칙으로 통과/실패를 매기는 것은 의미가 약하다.
- 시나리오와 채팅 테스트의 구분이 모호했다. 보조 패널은 좁아 챗봇을 실제처럼 시험하기에 부족했다.

## 결과

- `.atelierx/tests/scenarios/`를 없애고, 테스트 기록은 `.atelierx/tests/runs/<시각>.jsonl`만 남긴다.
- 테스트 화면은 로어북 활성화가 플랫폼 프리셋 규칙으로 근사한 것임을 알린다.
- 샘플 작품의 시나리오 파일을 지운다.
