# 0014. 기술 스택

- 날짜: 2026-10-03
- 상태: 채택

## 결정

| 영역 | 선택 |
|---|---|
| 서버 | Python 3.12, Starlette + uvicorn(비동기) |
| 화면 | TypeScript + React, Vite 빌드 |
| 편집기 | CodeMirror 6 |
| 데스크톱 창 | pywebview |

## 이유

- 서버: 이벤트 스트림, LLM 응답 스트리밍, 파일 감시 알림이 많아 비동기 틀이 다루기 쉽다. 의존성도 작다.
- 화면: JSX 미리보기가 어차피 React를 쓰므로 한 생태계로 맞춘다.
- 편집기: Markdown·JSX 강조와 큰 문서 편집에 충분하고 가볍다.
- 데스크톱 창: Python 하나로 배포 묶음을 만들 수 있다. 창 기능이 더 필요해지면 다시 본다.
