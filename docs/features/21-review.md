# 갤러리·검수

## 목적

만든 이미지를 작품·캐릭터·의상·표정별로 보고 통과·실패를 가린다. 통과한 이미지는 그 조합의 **채택 이미지**가 되고, 채택 이미지는
ZIP으로 내보내거나 데이터셋([22](22-datasets.md))의 재료로 쓴다. 비전 LLM이 먼저 보고 판정을 붙이는 **자동 검수**를 켤 수 있다.

## 사용 흐름

### 갤러리

1. 상단 메뉴 막대 "이미지 → 갤러리·검수". 편집 영역에 갤러리 탭이 열린다. 처음에는 지금 작품의 이미지만 보인다.
2. 왼쪽 트리: 모든 이미지 / 작품 → 캐릭터 → 의상(장수 표시), 그 밖의 폴더(생성·비교의 단일 생성, 도구 결과 등).
3. 거르기: 표정, 내 판정(미검수·통과·실패), AI 판정(없음·통과·실패·판단 어려움·오류), 채택만, 조합마다 최신만, 정렬(최신순·오래된
   순·코드순).
4. 격자는 썸네일과 표시(★ 채택, ✓/✗ 내 판정, AI 판정)를 보여 준다. 실패한 이미지는 흐리게.
5. 목록은 처음 연 때를 기준으로 고정한다. 그 뒤에 생긴 이미지는 "새 이미지 n장 보기"를 눌러야 들어온다(쪽 넘김이 흔들리지 않게).

### 검수

- 이미지를 누르면 크게 보이고, 옆에 생성 기록(프롬프트·negative, 모델·샘플러·스텝·CFG·시드·크기·LoRA·그림체 프리셋)이 나온다.
  프롬프트는 눌러서 복사한다.
- 키보드: `←`/`→` 이전·다음, `1`(또는 `P`) 통과, `2`(`F`) 실패, `3`(`U`) 미검수로, `R` 새 시드로 다시 생성, `Esc` 닫기.
- 실패에는 이유를 남긴다: 자주 쓰는 이유 버튼(손, 얼굴, 의상, 구도, 기타)과 메모.
- 여러 장: 체크, "이 페이지 선택", "조건에 맞는 것 모두 선택" 뒤 통과·실패·판정 취소·다시 생성을 한꺼번에.
- 판정 기록(누가 언제 무엇을 무엇으로)을 이미지마다 보여 준다.

### 채택

- 작품 이미지(대기열로 만든 것)를 통과시키면 그 조합(작품·캐릭터·의상·표정)의 채택 이미지가 된다. 같은 조합에 채택이 있으면
  새로 통과한 것으로 바뀐다.
- 채택 이미지를 실패·미검수로 바꾸면 채택이 풀린다.
- AI 판정은 참고용이다. 채택은 사람이 통과를 눌렀을 때만 된다.

### 다시 생성

- 이미지의 생성 기록에서 시드만 바꿔 대기열에 넣는다. 보정(후처리)한 이미지는 원래 설정으로 다시 만들고, 보정은 다시 하지 않는다고
  알린다.

### 자동 검수 (비전 LLM)

1. 설정 → 이미지 → "자동 검수"를 켠다. 어떤 연결·모델이 볼지는 설정 → LLM의 "이미지 검수" 작업에서 고른다(이미지를 읽을 수 있는
   모델이어야 한다). 외부 연결이면 작품마다 전송 동의를 받는다.
2. 자동 검수가 켜진 동안 대기열에 넣은 이미지는 각각 **검수 묶음**이 된다.
3. 대기열의 생성이 모두 끝나면 이미지 생성 서버의 메모리를 비우고, 비전 모델이 이미지와 그 생성 기록의 외모·의상·표정·구도를
   맞춰 본다. 생성과 검수가 GPU를 번갈아 쓰지 않게 한 번에 몰아서 한다.
4. 판정:
   - 통과 → "AI 통과 · 확인 필요". 사람이 보고 통과시키면 채택.
   - 분명한 실패 → 새 시드로 다시 생성하고 다시 검수한다. 설정한 횟수(기본 3)에 닿으면 "재생성 한도".
   - 판단 어려움 → "확인 필요". 통과라면서 문제를 말하는 답도 판단 어려움으로 본다.
   - 오류 → 세 번까지 다시 묻고, 그래도 안 되면 "확인 필요".
5. 사람이 그 조합의 이미지를 통과시키면 묶음은 끝나고, 대기 중인 재생성은 취소한다.
6. 갤러리의 "자동 검수" 패널에서 묶음 상태를 보고, 확인 필요·한도인 묶음은 "다시 검수"(다시 생성 없이), 끝난 묶음은 "끝난 것
   정리"로 치운다.
7. 검수가 끝나면 선택한 "모델 내리기 명령"(예: 로컬 LLM 서버의 모델 내리기)을 실행해 GPU를 비운다.

### 내보내기

- "채택 이미지 내보내기": 지금 보고 있는 범위(작품·캐릭터·의상)의 채택 이미지를 `<캐릭터>/<의상>/<표정>.png`(작품을 정하지 않으면
  앞에 작품 ID)로 묶은 ZIP.
- 채택 이미지를 배포 대상(R2)에 바로 올리는 것은 [25](25-deployment.md).
- 채택 이미지가 없는 필요한 조합은 미리 목록으로 알리고 뺀다. 필요한 조합은 완성도 보드 기준(의상 × 표정 라이브러리, 제외한 조합 빼고)이라
  한 번도 생성하지 않은 조합도 들어간다. 디자인이 없는 캐릭터는 이미지는 있지만 채택이 없는 조합만 센다.

### 완성도 보드

- 이미지 메뉴 "완성도 보드": 캐릭터마다 의상(행) × 표정(열) 격자. 칸은 미생성·생성됨(장수)·채택·제외로 표시하고, 대기열에 있는 칸은 테두리로 따로 보인다.
- 캐릭터·작품 진행률(채택/필요). 이미지가 있는 칸을 누르면 그 캐릭터·의상의 갤러리를 연다.
- "제외 편집"에서 칸, 또는 의상·표정 이름을 눌러 줄 전체를 제외하거나 다시 필요로 바꾼다.
- "미생성 생성"·"미채택 포함 생성"은 대기열에 없는 해당 조합을 생성 화면으로 넘긴다. 생성 화면에서 모델·프리셋을 고르고 장수를 확인한 뒤 올린다.
- "생성 정보 빼기"를 고르면 PNG의 생성 정보(프롬프트·설정·워크플로)를 지운 사본을 넣는다(공유용).

### 지우기와 출력 휴지통

- 고른 이미지 또는 상세 화면에서 "지우기"를 누르면 이미지와 그 기록을 **출력 휴지통**(`<출력 루트>/.trash/`)으로 옮긴다. 갤러리와
  이미지 도구 목록에서 빠진다.
- 갤러리의 "휴지통"에서 고른 것을 되살리거나(원래 자리로, 그 자리에 새 파일이 있으면 옆에 `_restored`로), 완전히 지우거나, 휴지통을
  비운다. 검수 결과는 경로·해시에 묶여 있으므로 되살린 이미지는 판정·채택이 그대로 돌아온다.

### 다른 화면으로 보내기

- 상세 화면의 "생성·비교에서 열기": 프롬프트·설정을 생성·비교로 넘기고 이 이미지를 기준으로 둔다([20](20-generation.md)).
- 고른 이미지의 "이미지 도구로 보내기": 이미지 도구 목록에 넣는다([24](24-image-tools.md)).

### 예외 흐름

- **기록 없음**: 앱 밖에서 넣은 이미지 등. 보기·판정은 되고 다시 생성은 안 된다.
- **바뀐 파일**(해시 다름): 검수 결과가 해시에 묶여 있으므로 미검수로 보인다. 화면에 보인 뒤 바뀐 파일에 판정을 누르면 거절한다.
- **연결 없음**: 자동 검수를 켤 때 "이미지 검수" 작업에 쓸 연결이 없으면 켜지지 않는다.

### 상태

- **비어 있음**: "조건에 맞는 이미지가 없습니다."
- **불러오는 중**: 썸네일은 차례로 채운다(`state/image/thumbnails/`에 WebP로 만들어 둔다, 지워도 다시 만듦).

## 데이터

| 파일 | 읽기·쓰기 | 형식 |
|---|---|---|
| 출력 루트 이미지와 `.json` | 읽기 | [생성 기록](../data-model.md#생성-기록) |
| 출력 루트 `reviews.json` | 읽기·쓰기 | [검수 결과](../data-model.md#검수-결과-출력-루트reviewsjson) |
| `config/image/review.json` | 읽기·쓰기 | 자동 검수 설정(켜기, 재생성 횟수, 지침, 모델 내리기 명령) |
| `state/image/review_rounds.json` | 읽기·쓰기 | 자동 검수 묶음 |
| `state/image/thumbnails/` | 읽기·쓰기 | 썸네일 |
| `state/image/hashes.json` | 읽기·쓰기 | 이미지 해시 캐시(지워도 다시 만듦) |
| 출력 루트 `.trash/` | 읽기·쓰기 | 지운 이미지와 기록, `index.json`(원래 경로·지운 때) |

## 규칙

- 출력 루트가 기준이다. 목록은 파일을 훑어 만들고, 기록이 바뀌거나 없어져도 목록은 깨지지 않는다.
- 파일 경로는 출력 루트 밖으로 나갈 수 없고, 링크(심볼릭 링크)는 따라가지 않는다.
- 출력 루트는 스냅샷에 넣지 않으므로 검수 결과도 이력이 없다. 대신 `reviews.json`은 원자적으로 쓰고 하나 전 사본을 남긴다.
- 비전 모델에는 이미지(768px로 줄인 JPEG)와 생성 기록의 외모·의상·표정·구도 부분만 보낸다. 작품 본문은 보내지 않는다.
- 다시 시작했을 때 검수 중이던 묶음은 "검수 대기"로 돌린다(같은 이미지를 다시 묻는다).

## API

| 요청 | 내용 |
|---|---|
| `GET /api/image/gallery?work&character&outfit&expression&human_status&auto_status&adopted&latest&sort&page&snapshot` | 목록 |
| `GET /api/image/gallery/tree` | 트리(작품·캐릭터·의상·표정별 장수, 그 밖의 폴더) |
| `GET /api/image/gallery/detail?path` | 이미지 하나의 생성 기록·검수 결과·판정 기록 |
| `GET /api/image/gallery/thumbnail?path` | 썸네일(WebP) |
| `POST /api/image/gallery/review` | 판정 `{verdict, items: [{path, sha256?}], note?}` |
| `POST /api/image/gallery/regenerate` | 새 시드로 다시 생성 `{items, review?}` |
| `POST /api/image/gallery/export/plan` | 내보낼 채택 이미지와 빠지는 조합 |
| `GET /api/works/{id}/image/board` | 완성도 보드: 표정 목록, 캐릭터별 의상·칸 상태(`state`, `images`, `queued`)·필요·채택 수 |
| `PUT /api/works/{id}/image/board/exclude` | 조합 제외·되돌리기 `{character_id, combos: ["의상/표정"], excluded}` |
| `POST /api/image/gallery/export` | ZIP `{filters, allow_partial, strip_metadata}` |
| `GET·PUT /api/image/review/settings` | 자동 검수 설정 |
| `GET /api/image/review/rounds`, `POST /api/image/review/rounds/{dismiss|retry}` | 자동 검수 묶음 |
| `POST /api/image/gallery/delete` | 출력 휴지통으로 옮기기 `{paths}` |
| `GET /api/image/trash`, `POST /api/image/trash/{restore|purge}` | 휴지통 목록, 되살리기·완전히 지우기 `{ids?}` |

## 단계
