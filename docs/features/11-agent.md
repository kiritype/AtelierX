# 에이전트 패널

## 목적

LLM과 대화하며 작품을 쓰고 다듬는다. 대화 방식은 **모드 지침**(사용자가 고칠 수 있는 마크다운)이 정하고, 에이전트가 바꿀 내용은
**파일 전체 교체 제안**으로 나와 검토 탭에서 골라 채택한다. 에이전트가 파일을 직접 고치는 일은 없다. 결정은
[0021](../decisions/0021-agent-panel.md).

## 사용 흐름

### 새 대화

1. 오른쪽 보조 패널 → **에이전트** 탭. 대화가 없으면 모드 카드가 보인다(아이디어 정리, 시작 상황 쓰기, 캐릭터 다듬기, 로어북 정리,
   JSX 만들기, 모순·누락 찾기, 자유 대화).
2. 카드를 누르면 새 대화가 생긴다. 범위는 모드의 기본값(현재 파일 또는 작품 전체)으로 정해지고, 범위 칩을 눌러 바꿀 수 있다
   (현재 파일 / 파일 고르기 / 작품 전체).
3. 질문을 쓰고 보낸다. 입력창 위에 "파일 n개 · 약 x 토큰 / 예산 y"가 보이고, 예산을 넘어 본문을 뺀 파일이 있으면 표시한다.
4. 응답은 스트리밍으로 온다. 사고 과정은 보여 주지 않고 글자 수만 표시한다.

### 첨부

- 편집기에서 글을 고르고 `Ctrl+L` → 에이전트 탭이 열리고 입력창 위에 첨부 칩(`인물/한서윤.md:12-30`)이 붙는다.
- 첨부 버튼으로 파일을 통째로 붙일 수도 있다. 첨부는 그 메시지에만 들어간다(범위는 대화 전체에 들어감).

### 제안 검토

1. 응답 속 제안은 카드로 보인다: 대상 경로, 새 파일 여부, 줄 수 변화, 경고.
2. **검토로 보내기** → 임시 항목(`agent_file`)이 생기고 검토 탭이 열린다.
3. 검토 탭은 원본과 제안의 차이를 덩어리(hunk)로 나눠 보여 준다. 덩어리마다 채택 여부를 고르고(기본 전부 채택) **채택**하면 저장된다.
   저장 직전에 `before_llm` 스냅샷을 만든다.
4. 새 파일 제안은 채택하면 파일이 생긴다.

### 예외

- **끊긴 제안**: 응답이 길이 한도로 끊겨 `<<<end>>>`가 없으면 검토로 보낼 수 없다. "이어서 써 줘"를 보내는 버튼이 나온다.
- **원본이 바뀜**: 제안을 만든 뒤 원본이 바뀌었으면 채택을 막고 "다시 요청"을 안내한다.
- **경고**: 새 내용이 원본보다 크게 줄었거나(60% 미만) 생략 표시("(이하 동일)", "…생략" 등)가 있거나, 머리 메타데이터의
  `id`·`kind`가 바뀌면 카드와 검토 탭에 경고한다. 채택은 막지 않는다.
- **범위 밖 경로**: 작품 밖, `.atelierx/` 안, `.md`·`.jsx`가 아닌 경로의 제안은 무시하고 카드에 이유를 쓴다.

### 대화 관리

- 패널 위쪽의 대화 목록에서 다른 대화로 바꾸거나 새 대화를 만든다. 이름은 첫 질문에서 따오고 바꿀 수 있다. 지우기는 확인을 거친다.

## 화면

```text
┌ 에이전트 ─────────────────────────┐
│ [캐릭터 다듬기 · 10/05 14:20 ▾] [+]│
│ 범위: [현재 파일: 인물/한서윤.md ▾] │
│───────────────────────────────────│
│ 나: 말투를 조금 더 건조하게…        │
│ 에이전트: 이렇게 바꿔 봤어요.        │
│ ┌ 제안: 인물/한서윤.md ──────────┐ │
│ │ 42줄 → 40줄 · 경고 없음        │ │
│ │ [검토로 보내기] [본문 보기]     │ │
│ └────────────────────────────────┘ │
│───────────────────────────────────│
│ [인물/한서윤.md:12-30 ×]           │
│ 파일 1개 · 약 1,820 토큰 / 4,915   │
│ ┌───────────────────────────────┐ │
│ │ 질문 입력 (Enter 보내기)        │ │
│ └───────────────────────────────┘ │
│ [로컬 · model ▾]          [보내기] │
└───────────────────────────────────┘
```

- 대화가 없을 때: 모드 카드 목록(이름, 설명 한 줄). 카드 목록 아래 "지침 편집" 링크(설정 → 지침).
- 보내는 중에는 보내기 버튼이 "멈추기"가 된다.

### 설정 → 지침

- 묶음(접기 가능): **에이전트 모드** / **작업 지침**(플랫폼 공통, 압축, 모순 검사, JSX 문구, 뼈대 작성) / **이미지 프롬프트** /
  **앱 고정 지시**(읽기 전용, 기본으로 접힘). 묶음 머리에 개수와 "수정됨 n".
- 맨 위에 검색 칸과 "바뀐 것만 보기".
- 접힌 줄: 이름, 설명 한 줄, 출처 배지(기본 / 수정됨 / 사용자 추가).
- 펼치면 그 자리에서 편집: 에이전트 모드는 이름·설명·기본 범위·순서 폼 + 본문 편집기, 다른 지침은 본문 편집기. 버튼은 저장,
  기본값과 비교, 기본값으로 되돌리기(편집기에 기본값을 넣음. 저장해야 반영), 지우기(사용자 추가 모드만, 확인을 거침).
- 한 번에 하나만 펼친다. 저장하지 않은 변경이 있으면 접거나 다른 항목을 펼칠 때 묻는다. 펼친 묶음은 브라우저에 기억한다.
- 에이전트 모드 묶음 끝에 **새 모드 추가**(빈 모드 또는 기존 모드 복제).

## 규칙

### 맥락 조립

1. **시스템 메시지** = 앱 고정 지시 → 모드 지침 본문 → `platform.md` → 플랫폼 규칙 요약(항목 종류별 용량 제한, 응답 속 컴포넌트 표기).
2. **작품 맥락**(시스템 메시지 끝) = 범위의 파일 목록(경로·종류·ID·크기, 본문을 넣었는지) → 범위의 본문(머리 메타데이터 포함, 파일마다
   `<<<file path="…">>>` 표지로 감쌈. 제안 형식과 같은 모양이라 모델이 따라 하기 쉽다).
3. **대화 기록** = 지난 턴들. 오래된 턴부터 예산에 맞춰 뺀다.
4. **이번 메시지** = 첨부(경로·줄 범위와 함께) + 질문.
5. 예산 = 모델의 맥락 길이(연결 카드의 모델별 값, 없으면 8192 토큰) × 0.6. 넘으면 본문을 뺀다: 첨부 → 현재 파일 → 나머지 순으로
   넣고, 못 넣은 파일은 목록에만 남기고 "본문 빠짐"으로 표시한다.
6. 예약 참조(`{{user}}`·`{{char}}`)는 바꾸지 않고 그대로 보낸다. 작성 도구이므로 원문 그대로 다룬다.

### 제안 해석

- `<<<file path="경로">>>` 다음 줄부터 `<<<end>>>` 앞 줄까지가 새 내용 전체다. 한 응답에 여러 개가 있을 수 있다.
- 경로는 작품 안 상대 경로로 정규화한다. 작품 밖·`.atelierx/`·항목이 아닌 확장자는 무시한다.
- 같은 경로가 한 응답에 두 번 나오면 마지막 것을 쓴다.

### 외부 전송

- 외부 연결이면 범위의 본문과 첨부가 그 서비스로 간다. 작품×연결 동의는 [03-llm](03-llm.md)을 따른다.

## API

| 요청 | 내용 |
|---|---|
| `GET /api/works/{id}/agent/modes` | 이 작품에서 쓸 모드 목록(겹침 적용) |
| `GET /api/works/{id}/agent/sessions` · `POST …` | 대화 목록 · 새 대화 `{mode, scope}` |
| `GET /api/works/{id}/agent/sessions/{sid}` · `PATCH …` · `DELETE …` | 대화 읽기 · 이름·범위 바꾸기 · 지우기 |
| `POST …/sessions/{sid}/preview` | 보내기 전 맥락 크기 `{message, attachments}` → 파일·토큰·예산·빠진 파일 |
| `POST …/sessions/{sid}/send` | 메시지 보내기 → 스트림(이벤트: `context`, `delta`, `thinking`, `end{proposals, finish_reason}`) |
| `POST …/sessions/{sid}/proposals/{turn}/{n}/review` | 제안을 임시 항목으로 → `{draft_id}` |
| `POST /api/works/{id}/agent-drafts/{did}/apply` | 고른 결과 `{text}`를 저장(새 파일이면 만듦) |
| `GET /api/guidelines` · `GET/PUT/DELETE /api/guidelines/{이름}` | 전역 지침 목록(묶음·출처) · 읽기·저장·지우기 |

## 단계

- **0.0.3**: 에이전트 탭, 모드 카드, 범위(현재 파일·파일 고르기·작품 전체), 첨부, 스트리밍, 파일 전체 교체 제안 → 검토(덩어리 채택),
  대화 기록, 기본 모드 지침, 설정 → 지침(전역).
- **다음**: 플랫폼 프리셋·작품 지침을 같은 화면 구성 요소로 편집, 정해진 작업(압축·모순 검사 등)을 대화에서 "실행"으로 연결,
  모델이 파일을 찾는 도구 호출, 제목 단위 교체.
