## 문서 형식

각 기능 문서는 아래 순서를 따른다. 해당 없는 절은 생략한다.

```markdown
# <기능 이름>

## 목적
무엇을, 왜. 두세 문장.

## 사용 흐름
사용자가 하는 일을 순서대로. 대표 흐름 하나 + 예외 흐름.

## 화면
배치, 주요 동작, 상태(비어 있음·불러오는 중·오류).

## 데이터
읽고 쓰는 파일. 형식은 data-model.md를 링크로 참조하고 여기서 다시 정의하지 않는다.

## 규칙
검사, 제한, 안전장치(스냅샷, 확인 창, 외부 전송 확인).

## API
서버 엔드포인트 (요청·응답 요약).

## 단계
처음 만들 범위와 나중 범위.

## 정할 것
결정이 필요한 항목. 결정되면 decisions/에 기록하고 여기서 지운다.
```
