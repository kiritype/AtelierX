# 데이터셋

## 목적

검수를 통과한 이미지를 골라 LoRA 학습용 데이터셋을 만든다. 이미지마다 캡션을 만들고 고친다. 데이터셋은 사람이 고른 선택과
고친 캡션이라 다시 만들 수 없으므로 작품 폴더에 두고 스냅샷으로 지킨다([data-model.md 이미지 모듈 데이터](../data-model.md#이미지-모듈-데이터)).

## 사용 흐름

### 만들기

1. 이미지 → LoRA. 왼쪽에서 캐릭터(이미지 디자인이 있는 캐릭터)를 고르고 "데이터셋" 탭을 연다.
2. "새 데이터셋"에서 대상 의상(하나 또는 여럿)을 고른다. 그 의상의 작품 이미지가 후보로 보이고(★ 채택, ✓ 통과, ✗ 실패),
   처음에는 채택 이미지가 골라져 있다. "채택만", "통과한 것 전부"로 한 번에 고르거나 하나씩 넣고 뺀다.
3. 트리거: 캐릭터 트리거(비우면 이미지 디자인의 트리거, 없으면 `w001_c001`), 의상 트리거(의상 하나짜리 데이터셋이면
   `w001_c001_o01`이 자동으로 들어감, 비우면 쓰지 않음).
4. "데이터셋 만들기" → `.atelierx/image/characters/<ID>/datasets/D001.json`. 이름은 비우면 의상 이름.

### 캡션

- 만들 때 이미지마다 생성 기록에서 자동 캡션을 만든다(아래 규칙).
- 캡션 표에서 고치고 "캡션 저장". 고친 캡션은 "직접 고침" 표시가 붙고, 이미지를 다시 고르거나 "자동 캡션 다시 만들기"를 해도 그대로 남는다.
- 트리거를 바꾼 뒤 "자동 캡션 다시 만들기"를 누르면 고치지 않은 캡션만 새 트리거로 바뀐다.

### 학습 도구용으로 내보내기

- 학습([23](23-lora-training.md))을 시작하면 앱이 데이터셋을 학습 도구가 읽는 형태(PNG + 같은 이름의 `.txt` 캡션)로 학습 도구의
  `image_dataset/<결과 이름>/`에 만든다. 같은 이름의 예전 캐시는 먼저 지운다.

### 예외 흐름

- **기록 없는 이미지**: 캡션을 만들 수 없어 넣을 수 없다고 알린다.
- **이미지가 바뀜**(해시 다름): 학습을 시작할 때 막고 어느 이미지인지 알린다. 데이터셋을 다시 만들면 새 해시로 바뀐다.

## 데이터

| 파일 | 읽기·쓰기 | 형식 |
|---|---|---|
| `.atelierx/image/characters/<ID>/datasets/<D###>.json` | 읽기·쓰기 | [데이터셋](../data-model.md#데이터셋-datasetsdjson) |
| 출력 루트 이미지의 `.json`, `reviews.json` | 읽기 | 생성 기록(캡션 재료), 검수 결과(채택) |

## 규칙

### 자동 캡션

- 학습 도구 안내의 순서: 등급(이미지 라이브러리 등급 `general` → `safe` 등), 인원(`1girl`), 캐릭터 트리거, 의상 트리거, 그다음
  구도·단색 배경·표정 태그.
- 외모·의상 태그는 일부러 넣지 않는다. 트리거가 그 캐릭터의 외모(와 의상)를 익히게 하기 위해서다.
- 화풍·품질 태그, 자연어 문장은 넣지 않는다.

### 그 밖

- 데이터셋은 이미지를 복사하지 않고 참조만 한다(경로 + 해시 + 크기). 학습할 때만 복사본을 만든다.
- 데이터셋 파일은 스냅샷에 들어간다.

## API

| 요청 | 내용 |
|---|---|
| `GET /api/works/{id}/image/lora/{cid}` | 데이터셋·학습 기록·쓰는 LoRA |
| `GET /api/works/{id}/image/lora/{cid}/candidates?outfits` | 후보 이미지(채택·판정 표시) |
| `POST /api/works/{id}/image/lora/{cid}/datasets` | 만들기·다시 만들기 `{id?, name?, outfits, triggers?, paths?}` (paths가 없으면 채택 이미지) |
| `POST …/datasets/{did}/captions` | 캡션 저장 `{items: {경로: 캡션}}`, 자동 캡션 다시 만들기 `{rebuild, triggers?}` |
| `DELETE …/datasets/{did}` | 지우기 |

## 단계

- **I6(구현)**: 만들기·다시 고르기, 자동 캡션과 직접 고침 유지, 트리거, 학습 도구용 내보내기.
- **이후**: 데이터셋 복제, 모든 캡션에서 태그 바꾸기, 표정·구도 분포 표시, 태거 결과로 캡션 보충.
