# 공통 화면 틀

## 목적

모든 기능이 들어가는 바깥 틀을 정한다. 첫 실행과 잠금, 작품 안에서의 기본 배치(파일 트리 · 편집 영역 · 상태 표시줄),
작업 대기열과 알림처럼 여러 기능이 함께 쓰는 부분을 다룬다. 각 기능의 내부 화면은 해당 기능 문서에서 정한다.

## 사용 흐름

### 첫 실행

1. 앱을 켠다. 금고(`config/vault.json`)가 없으면 첫 실행 화면이 열린다.
2. 화면 언어를 고른다(한국어 / English).
3. 마스터 비밀번호를 두 번 입력한다. 화면에 "API 키를 암호화하고 실행할 때마다 확인한다. 잊으면 키만 다시 입력하면 되고
   작품은 그대로다"를 안내한다.
4. 금고가 만들어지고 작품 선택 화면으로 간다. 작품이 하나도 없으면 "샘플 작품 열기"와 "새 작품 만들기"를 보여 준다.

### 실행

1. 앱을 켜면 잠금 화면이 열린다. 비밀번호를 입력하면 금고가 열리고 서버가 세션을 발급한다.
2. 작품 선택 화면이 열린다. 마지막으로 연 작품이 맨 앞에 있다. 작품을 고르면 그 작품의 창이 된다.

### 작품 안에서

1. 왼쪽 파일 트리에서 파일을 열면 가운데 편집 영역에 탭으로 열린다. 파일은 몇 개든 탭으로 열 수 있다.
2. 왼쪽 활동 막대로 검색, 관계도, 용어집, 이미지, 임시 항목, 이력, 휴지통 화면을 오간다.
3. 상단 바의 **테스트**를 누르면 작품 창 전체가 테스트 화면으로 바뀐다([08](08-chat-test.md)). **← 작업으로**로 돌아온다.
4. LLM 작업이나 내보내기처럼 시간이 걸리는 일은 작업 대기열에 들어가고, 진행 상황은 상태 표시줄과 대기열 패널에 보인다.
   끝나면 알림이 뜬다(예: "압축 후보 3개가 준비됐어요 — 검토하기").

### 잠금과 잠금 해제

- 상단 바의 잠금 버튼, 또는 자동 잠금(설정, 기본 꺼짐)으로 잠근다. 잠그면 서버 메모리의 인증 정보를 지우고 잠금 화면을 보인다.
- 잠금 해제는 비밀번호 입력. 열려 있던 화면과 탭은 그대로 돌아온다.

### 예외 흐름

- **비밀번호를 잊음**: 잠금 화면의 "비밀번호를 잊었어요" → 확인 창("등록한 API 키 등 인증 정보가 모두 지워진다. 작품 데이터는
  그대로다") → 새 비밀번호 설정 → 설정 화면의 금고에서 인증 정보를 다시 입력한다.
- **비밀번호 틀림**: 다시 시도할 때까지의 대기 시간을 점점 늘리고 남은 시간을 보여 준다.
- **저장하지 않은 변경이 있는 채로 작품 전환·종료·잠금**: 저장할지 묻는다. 잠금은 저장되지 않은 내용을 화면에 그대로 둔 채
  잠그며, 해제 뒤 이어서 편집할 수 있다.
- **서버 연결 끊김**: 상단에 "서버에 연결할 수 없어요. 다시 연결 중…"을 띄우고 편집은 막지 않는다. 다시 연결되면 저장되지
  않은 변경을 저장한다.
- **데이터 형식이 앱보다 새 버전**: 해당 작품을 읽기 전용으로 열고 상단에 안내한다([data-model.md 버전](../data-model.md#버전)).

## 화면

### 첫 실행 · 잠금

화면 가운데 작은 카드 하나. 첫 실행은 언어 선택, 비밀번호 두 칸, 안내 문구, "시작하기". 잠금은 비밀번호 한 칸, "열기",
"비밀번호를 잊었어요".

### 작품 선택

잠금을 해제하면 나오는 화면. 작품 카드 목록(마지막으로 연 작품이 맨 앞), 검색, "새 작품", "샘플 작품". 상세는
[01-works](01-works.md).

### 작품 화면 배치

창 하나에 작품 하나를 연다. 다른 작품으로 가려면 상단 바의 작품 이름을 눌러 작품 선택 화면으로 돌아간다. 작품 안의
파일은 탭으로 자유롭게 연다. 텍스트 편집기와 같은 배치다.

```text
┌───────────────────────────────────────────────────────────────────────────────┐
│ 청원고 ▾  작품 편집 도구 이미지  테스트           [검색]   ⧗1  🔔  ⚙  🔒     │ 상단 바
├──┬──────────────┬──────────────────────────────────────────┬──────────────────┤
│📁│ 메인.md      │ 메인.md │ 한서윤.md ● │ 상태창.jsx │       │ 검사 │ 검토  │
│🔗│ 인물/        ├──────────────────────────────────────────┼──────────────────┤
│📖│  ├ 한서윤.md │ [상단 메타데이터 폼]                     │ ⚠ 키워드 겹침   │
│🖼│  └ 김도현.md │ ─────────────────────────────────────────│ ⓘ 이미지 오래됨 │
│📥│ 세계관/      │ ## 식별                                  │ ✓ 용량 63%      │
│🕘│ UI/          │ …                                        │                  │
│🗑│ 메모/        │                                          │                  │
├──┴──────────────┴──────────────────────────────────────────┴──────────────────┤
│ ● 저장 안 됨   2,840 / 4,500 B   전체 21,300 B   generic   LM Studio ●   ⧗ 압축 1/3 │ 상태 표시줄
└───────────────────────────────────────────────────────────────────────────────┘
```

| 영역 | 내용 |
|---|---|
| 상단 바 | 작품 이름(눌러서 작품 선택 화면으로), 메뉴 막대(작품: 작품 설정·내보내기·스냅샷 만들기·작품 목록·잠금 / 편집: 빠른 열기·검색·이름 일괄 변경 / 도구: 뼈대 작성·관계도·용어집·본문에서 찾기·모순 검사 / 이미지: 프롬프트 라이브러리·생성·생성 대기열·생성·비교·갤러리·검수·이미지 도구·LoRA — 이미지 화면은 편집 영역에 탭으로 열림, [결정 0018](../decisions/0018-image-module-port.md)), 테스트(테스트 화면 ↔ 작업 화면), 작품 안 검색, 작업 대기열(진행 중 개수), 알림, 설정, 잠금 |
| 활동 막대 | 아이콘 아래에 이름을 함께 표시. 파일 트리, 검색, 관계도, 용어집, 이미지, 임시 항목(검토 대기 개수 배지), 이력, 휴지통. 누르면 사이드 패널이 바뀐다(관계도·용어집은 편집 영역에 탭으로 열림) |
| 사이드 패널 | 활동 막대에서 고른 화면. 너비 조절·접기 가능 |
| 편집 영역 | 탭으로 여러 파일·화면을 연다. 탭은 끌어서 순서를 바꾸고, 저장하지 않은 탭에는 점을 표시한다 |
| 보조 패널 | 편집 영역 오른쪽. 탭으로 "검사"(현재 파일의 규칙 검사 결과), "검토"(LLM 결과 검토·채택)를 전환한다. 너비 조절·접기 가능. 0단계에서는 틀만 두고 내용은 각 기능 단계에서 채운다 |
| 상태 표시줄 | 저장 상태, 현재 파일 용량 / 제한, 작품 전체 용량, 연결된 플랫폼 프리셋, LLM 연결 상태, 진행 중 작업 |

- 글꼴과 아이콘: 화면 글꼴은 앱에 포함한 Pretendard(기본 14px)다. 서술 문서는 편집기와 미리보기 모두 15px이고(편집기 줄 간격 1.6), JSX·코드·로그는 고정폭 글꼴을 쓴다. 아이콘은 Lucide 한 벌로 통일한다.
- 상태 표시줄의 각 항목은 누르면 관련 화면으로 간다(용량 → 규칙 검사, 플랫폼 프리셋 → 작품 설정, 작업 → 대기열 패널).
- 용량 수치는 제한의 90%를 넘으면 경고색, 넘으면 오류색으로 표시한다.

### 작업 대기열 패널

상단 바의 대기열 아이콘을 누르면 열리는 목록.

| 열 | 내용 |
|---|---|
| 작업 | 종류와 대상(예: "압축 · 한서윤.md") |
| 상태 | 대기, 실행 중(진행률), 완료, 실패, 취소 |
| 작업 | 취소, 실패한 작업 다시 시도, 결과 열기(임시 항목 검토 등) |

- 작업 종류: LLM 작업(압축, 이미지 프롬프트 변환, JSX 프롬프트용 문구, 뼈대 작성, 관계 찾기, 모순 검사), 테스트 실행, 내보내기, (7단계) 이미지 생성·학습.
- GPU를 쓰는 작업은 한 번에 하나씩 실행한다. 외부 API 작업은 동시에 여러 개 실행할 수 있다(동시 실행 수는 설정).

### 알림

- 작업 완료·실패, 외부에서 파일이 바뀜, 형식 변환 필요 같은 일을 화면 오른쪽 아래 짧은 알림으로 띄운다.
- 지나간 알림은 상단 바의 알림 목록에서 다시 볼 수 있다. 알림에는 관련 화면으로 가는 동작을 하나 붙일 수 있다.

### 상태

- **비어 있음**: 작품이 없으면 작품 목록에 "샘플 작품 열기", "새 작품 만들기". 파일 트리가 비어 있으면 "새 파일"·"새 폴더".
- **불러오는 중**: 작품을 여는 동안 파일 트리 자리에 진행 표시.
- **오류**: 문장 하나로 무엇이 잘못됐고 무엇을 하면 되는지 보여 준다. 서버 예외 문장을 그대로 보이지 않는다.

### 단축키

| 키 | 동작 |
|---|---|
| `Ctrl+S` | 저장 |
| `Ctrl+P` | 파일 빠른 열기(이름으로 찾기) |
| `Ctrl+Shift+F` | 작품 안 검색 |
| `Ctrl+W` | 탭 닫기 |
| `Ctrl+Shift+L` | 잠금 |

| 작업 대기열 | `state/queue.json` | 앱을 다시 켜면 대기 중이던 작업을 보여 주고 다시 실행할지 묻는다 |

## 규칙

- 앱은 한 번에 하나만 실행한다. 다시 실행하면 새 창을 띄우지 않고 열려 있는 창을 앞으로 가져온다. 같은 앱 폴더를 두
  프로세스가 동시에 쓰지 않게 하기 위해서다(개발 중 브라우저로 쓸 때는 막지 않는다).
- 창 하나에 작품 하나다. 작품 안의 파일은 탭으로 개수 제한 없이 연다.
- 작품 폴더의 파일이 앱 밖에서 바뀌면(다른 편집기, 동기화 도구 등) 파일 트리를 갱신하고, 열린 탭의 파일이면 알린다.
  처리 방식은 02-editor에서 정한다.
- 인증 전에는 첫 실행·잠금 화면 외의 화면과 서버 API를 쓸 수 없다. 서버는 인증 관련 요청 외에는 세션을 확인한다
  (세션 방식은 architecture.md).
- 잠그면 서버 메모리의 인증 정보를 지운다. 실행 중인 외부 API 작업은 끝까지 진행하고, 대기 중인 외부 API 작업은 잠금 해제까지
  시작하지 않는다.
- 화면에 보이는 모든 문장은 i18n 키로 관리한다. 서버가 보내는 메시지도 키와 영어 기본 문장을 함께 보낸다.
- 오류·알림 문장에 인증 정보나 서버 내부 경로를 넣지 않는다.
- 외부 API를 부르는 작업은 처음 실행할 때 "이 작업은 내용을 외부 서비스로 보낸다"를 확인받는다(상세는 03-llm).

## API

요청·응답 요약. 경로와 형식의 상세는 구현 단계에서 정한다.

| 요청 | 내용 |
|---|---|
| `GET /api/auth/status` | `{initialized, unlocked}`. 첫 실행·잠금 화면 결정에 쓴다 |
| `POST /api/auth/setup` | 첫 실행: `{password, language}` → 금고 생성, 세션 발급 |
| `POST /api/auth/unlock` | `{password}` → 세션 발급. 틀리면 다음 시도까지 남은 시간 |
| `POST /api/auth/lock` | 잠금 |
| `POST /api/auth/reset` | 금고 초기화(확인 문구 필요) → 새 비밀번호 설정으로 |
| `GET /api/jobs` · `POST /api/jobs/{id}/cancel` · `POST /api/jobs/{id}/retry` | 작업 대기열 |
| `GET /api/events` | 서버 → 화면 이벤트 스트림: 작업 진행, 알림, 외부 파일 변경, 잠금 |
| `GET /api/settings` · `PUT /api/settings` | 사용자 설정 |
| `GET /api/ui-state` · `PUT /api/ui-state` | 화면 상태 |

## 단계

- **0단계**: 첫 실행, 잠금·잠금 해제, 단일 실행, 작품 선택에서 작품 창으로 가는 흐름, 작품 화면 배치(상단 바·활동 막대·사이드
  패널·탭·보조 패널 틀·상태 표시줄), 작업 대기열(LLM 작업, 내보내기), 알림, 단축키, 화면 언어 전환.
- **이후**: 자동 잠금, GPU 작업(7단계), 명령 팔레트, 탭 분할 보기.
