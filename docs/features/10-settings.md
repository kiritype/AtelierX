# 설정

## 목적

작품에 묶이지 않는 앱 전체 설정을 한곳에서 다룬다. 화면 언어·자동 저장 같은 일반 설정, 플랫폼 프리셋, 전역 가이드라인,
LLM 연결, 금고(인증 정보·마스터 비밀번호), 이미지 생성 연결, 저장 공간을 포함한다. 작품마다 다른 설정은
[01-works](01-works.md)의 작품 설정에서 다룬다.

## 사용 흐름

### 설정 열기

- 상단 바의 설정 버튼 또는 작품 선택 화면의 설정. 작품 창에서는 편집 영역에 탭으로 열리고, 작품 선택 화면에서는 화면 전체로 열린다.
- 왼쪽에 묶음 목록, 오른쪽에 내용. 바꾼 값은 바로 저장된다(저장 버튼 없음).

### 플랫폼 프리셋 만들기

1. 플랫폼 프리셋 → "새 프리셋" → 바탕으로 쓸 프리셋 고르기(`generic` 또는 기존 프리셋) → ID(= 폴더 이름이자 연결 태그)와
   이름 입력.
2. 묶음별로 값을 고친다: 세는 방식, 용량 제한, 로어북 활성화, JSX 규칙.
3. 프리셋 가이드라인 탭에서 이 프리셋 전용 가이드라인 파일을 만들고 편집한다.
4. "새 작품에 기본으로 연결"을 켜면 `default_platform_preset`이 된다(하나만).

### 플랫폼 프리셋 고치기 · 이름 바꾸기 · 지우기

- 값을 고치면 이 프리셋에 연결된 모든 작품에 바로 반영된다. 화면 위에 "연결된 작품 3개"를 보여 준다.
- **ID 바꾸기**: 연결된 작품들의 태그도 함께 바꾼다. 영향받는 작품 목록을 보여 주고 확인을 받는다. 작품마다 `before_bulk`
  스냅샷을 만든다.
- **지우기**: 연결된 작품 목록을 보여 주고 확인을 받는다. 프리셋 폴더는 `data/.trash/`로 간다. 작품의 태그는 그대로 남고
  (연결만 끊긴 분류용 태그가 됨), 기본 프리셋이었다면 기본 지정이 풀린다.
- `generic`은 앱 기본값과 같으므로 읽기 전용이다. 고치려면 복제해서 새 프리셋을 만든다.

### 플랫폼 프리셋 가져오기 · 내보내기

- 내보내기: 프리셋 폴더(`preset.json` + `guidelines/`)를 고른 위치에 복사한다. 다른 사람과 플랫폼 규칙을 나눌 때 쓴다.
- 가져오기: 프리셋 폴더를 고르면 `data/platforms/`에 복사한다. 같은 ID가 있으면 새 ID를 고르게 한다.

### 전역 가이드라인

> 0.0.3부터 화면은 **설정 → 지침**(묶음·항목 접기)이다. 배치와 동작은 [11-agent](11-agent.md)의 "설정 → 지침"을 따른다.

1. 가이드라인 → 전역 가이드라인 파일 목록(`data/guidelines/`). 파일을 누르면 편집 영역에 탭으로 열린다(일반 Markdown 편집).
2. 각 파일 옆에 쓰는 기능을 표시한다(예: `compression.md` — 압축). 정해진 이름이 아닌 파일은 "참고 문서".
3. "덮어쓴 곳"에서 같은 이름의 가이드라인을 덮어쓴 프리셋·작품 목록을 보고, 원래 것과 비교할 수 있다.
4. 앱에 포함된 기본 가이드라인으로 되돌리기(파일별). 되돌리기 전 내용은 휴지통으로 간다.

### LLM 연결

1. LLM 연결: 처음부터 있는 "로컬 LLM" 연결의 주소를 확인한다. 다른 서버는 "연결 추가"(OpenAI 호환)로 이름, 주소, 인증 정보
   (필요하면 금고 항목)를 입력한다.
2. "연결 시험"으로 응답과 모델 목록을 확인한다.
3. 작업별 기본 모델(압축, 이미지 프롬프트 변환, JSX 프롬프트용 문구, 뼈대 작성, 모순 검사, 테스트)을 고른다. 정하지 않은
   작업은 로컬 LLM을 쓴다.
4. 상세는 03-llm.

### 금고

1. 금고 → 인증 정보 목록(이름, 종류, 가린 값, 메모, 쓰는 곳).
2. "추가": 이름, 종류(`llm_api_key`, `service_token`, `server_auth`, `other`), 값, 메모. 값은 저장 뒤 다시 보이지 않는다.
3. 값을 다시 보려면 "보기" → 마스터 비밀번호 입력.
4. 지우기: 이 항목을 쓰는 연결이 있으면 목록을 보여 주고 확인을 받는다. 인증 정보는 휴지통으로 가지 않고 바로 지워진다
   (금고 밖에 평문으로 두지 않기 위해).
5. "비밀번호 바꾸기": 지금 비밀번호와 새 비밀번호 두 번.
6. "금고 초기화": 확인 문구 입력 → 모든 인증 정보 삭제 → 새 비밀번호 설정. 작품 데이터는 영향이 없다.

### 이미지 (태그 사전: 5단계, 생성 연결: 7단계)

- **태그 사전**: 기본으로 Danbooru 목록이 들어 있다. "가져오기"로 같은 양식의 CSV를 더해 `data/tags/`에 복사한다. 목록(이름,
  태그 수, 가져온 날), 지우기, 기본 목록 되살리기. 위치·양식 안내는 `defaults/tags/README.md`. 동작은
  [06-image-prompts](06-image-prompts.md).
- **이미지 생성 연결**: 아래.

이미지 생성 서버 연결, 모델 폴더와 계열, GPU 대기 규칙, 자동 검수, LoRA 학습(학습 도구 폴더, LoRA 출력 폴더, 학습 모델). 상세는
이미지 모듈 문서(20번대).

### 설치 ([결정 0019](../decisions/0019-install-page.md))

이미지 기능에 필요한 외부 구성 요소를 영역별로 받는다. 영역마다 상태(있음/없음, 판)와 버튼이 있고, 누를 때만 실행한다. 한 번에
하나씩 실행하고, 진행은 아래 로그에 보이며 멈출 수 있다.

1. **보조 도구 (uv, Git)**: PC에 있으면 그것을 쓰고, 없으면 앱 폴더 `bin/`에 휴대용으로 받는다.
2. **이미지 생성 서버 확장 노드**: 시험한 판의 노드와 앱의 노드 묶음([24](24-image-tools.md)). 대상이 없어진 링크 등 막는 것을 알린다.
   "이미지 생성 서버 다시 시작"(앱이 실행한 서버면 앱이, 아니면 서버의 관리 기능으로).
3. **모델**: 묶음(LoRA 학습용 Anima 기반, 감지 모델, 업스케일)별 받기. 이미지 생성 서버가 읽는 폴더(공유 모델 폴더 우선)에 받고
   sha256으로 확인한다. 묶음마다 라이선스 링크를 보여 준다. 계정이 필요한 곳의 모델은 링크와 넣을 폴더만 안내한다.
4. **LoRA 학습 도구**: anima_lora를 시험한 판으로 앱 폴더 `vendor/`에 받고, 전용 Python 환경을 만들고(`uv sync`), 모델 경로 패치를
   적용한다. 비어 있는 학습 설정(학습 도구 폴더, LoRA 출력 폴더, 학습 모델)은 채운다([23](23-lora-training.md)).

### 저장 공간

- 데이터 루트, 출력 루트, 작품별 이력, 휴지통(작품 안 휴지통 합계 + 지운 작품), 캐시의 크기를 보여 준다.
- 동작: 작품별 "이력 지금 정리", "캐시 비우기", 휴지통 화면으로 가기.

### 꾸러미·백업

설정 → 꾸러미·백업에서 설정을 파일 하나(ZIP)로 받고, 다른 PC나 새 앱 폴더에서 가져온다.

- 담을 것: 일반 설정, 플랫폼 프리셋, 전역 지침, LLM 연결과 작업별 모델(인증 정보는 참조만), 페르소나, 이미지 프롬프트 라이브러리,
  생성 프리셋, 이미지 자동 검수 설정, 태깅 제외 태그. 이 PC에만 맞는 값(ComfyUI 위치, 모델·LoRA·학습 도구 경로, GPU 기준)은 담지 않는다.
- 인증 정보(금고)는 고를 때만, 이 앱의 마스터 비밀번호로 암호화된 채 담는다. 가져올 때 그 비밀번호를 받아 항목을 이 앱의 금고에 더한다.
- 가져오기는 고른 영역만 바꾼다. 바뀌는 파일은 먼저 `state/packages/backups/settings-<시각>.zip`에 남긴다. 폴더(플랫폼 프리셋·지침 등)는
  같은 이름의 파일만 바꾸고 나머지는 둔다.
- API: `POST /api/packages/settings/export {areas}`, `POST /api/packages/upload`, `POST /api/packages/settings/import {token, areas, vault_password?}`.

```text

│ 일반            │ 플랫폼 프리셋                       [새 프리셋]   │
│ 플랫폼 프리셋 ◀ │ ┌──────────────────────────────────────────────┐ │
│ 가이드라인      │ │ generic   범용        읽기 전용     작품 2   │ │
│ LLM 연결        │ │ cafe-bot  카페 챗봇   ★ 기본        작품 3   │ │
│ 금고            │ └──────────────────────────────────────────────┘ │
│ 이미지 생성     │ cafe-bot                                          │
│ 설치            │                                                   │
│ 저장 공간       │  세는 방식  [UTF-8 바이트 ▾]                      │
│ 정보            │  메인 프롬프트 최대 [16000]  항목 최대 [4500]      │
│                 │  키워드 비교 [부분 일치 ▾]  대소문자 구분 [ ]      │
│                 │  검사할 메시지 수 [2]  예산 [없음]                 │
│                 │  JSX 금지 [import] [export]  훅 [useState] …      │
```

| 묶음 | 내용 |
|---|---|
| 일반 | 화면 언어, 자동 저장(켬/끔, 쉬는 시간), 자동 잠금(끔/분), 저장 묶음 스냅샷 간격, 이력 자동 정리 기준, 외부 API 작업 동시 실행 수 |
| 플랫폼 프리셋 | 목록(이름, 기본 표시, 읽기 전용 표시, 연결된 작품 수), 선택한 프리셋의 묶음별 값, 프리셋 가이드라인, 가져오기·내보내기 |
| 가이드라인 | 전역 가이드라인 목록, 쓰는 기능, 덮어쓴 곳 |
| LLM 연결 | 연결 목록, 연결 시험, 작업별 기본 모델 |
| 금고 | 인증 정보 목록, 추가·보기·지우기, 비밀번호 바꾸기, 금고 초기화 |
| 이미지 | 태그 사전 가져오기·지우기(5단계), 이미지 생성 연결(7단계) |
| 설치 | 보조 도구, 이미지 생성 서버 확장 노드, 모델, LoRA 학습 도구 |
| 저장 공간 | 크기, 정리 동작 |
| 정보 | 앱 버전, 앱 폴더 위치, 데이터 형식 버전(`layout_version`), 오픈 소스 고지 |

### 상태

- **비어 있음**: LLM 연결이 없으면 "LLM 연결을 추가하면 압축·변환·테스트를 쓸 수 있어요"와 "연결 추가".
  금고가 비면 "외부 API를 쓸 때 키를 여기에 등록해요".
- **오류**: 입력값이 틀리면 입력란 아래에 바로 보여 준다(예: "0보다 큰 숫자를 넣어 주세요", "이미 쓰는 프리셋 ID예요").

`config/settings.json`의 주요 키:

| 키 | 기본값 | 뜻 |
|---|---|---|
| `language` | 첫 실행에서 고름 | 화면 언어 |
| `autosave` | `{"enabled": true, "delay_ms": 1000}` | 자동 저장 |
| `autolock_minutes` | `null` | 자동 잠금(없으면 끔) |
| `snapshot_interval_minutes` | `10` | 저장 묶음 스냅샷 간격 |
| `history_prune` | `{"keep_recent": 200, "daily_days": 30}` | 이력 자동 정리 기준 |
| `jobs` | `{"api_concurrency": 2}` | 이 PC의 GPU를 쓰지 않는 LLM 요청의 동시 실행 수 |
| `chat_runs_keep` | `100` | 작품마다 남길 테스트 기록 수 |
| `default_platform_preset` | `null` | 새 작품에 연결할 플랫폼 프리셋 |
| `image` | 비어 있음 | 태그 사전 목록, 이미지 생성 서버 주소, 모델·LoRA 폴더, 학습 도구(`training`). 상세 키는 20·23을 구현할 때 정한다 |

## 규칙

- 설정 값은 바꾸는 즉시 저장한다. 잘못된 값은 저장하지 않고 입력란에 오류를 보인다.
- 금고의 값은 화면에 가린 형태로만 보낸다. "보기"는 비밀번호를 다시 확인한 뒤 그 항목 하나만 보여 준다.
- 플랫폼 프리셋 ID는 폴더 이름이므로 ID 규칙(영문, 숫자, `_`, `-`)을 따른다. `generic`은 예약되어 있다.
- 프리셋을 바꾸면 연결된 작품의 용량·검사 결과를 다시 계산한다.
- 경로 설정(LoRA 폴더 등)은 앱 폴더 안이면 상대 경로로 저장한다.

## API

| 요청 | 내용 |
|---|---|
| `GET /api/settings` · `PATCH /api/settings` | 일반 설정 |
| `GET /api/platforms` · `POST /api/platforms` | 프리셋 목록, 만들기(`{id, name, base}`) |
| `GET /api/platforms/{id}` · `PUT /api/platforms/{id}` | 프리셋 읽기·저장 |
| `POST /api/platforms/{id}/rename` | ID 바꾸기(영향 미리보기 → 확인 후 실행) |
| `DELETE /api/platforms/{id}` | 지우기(휴지통으로) |
| `POST /api/platforms/import` · `POST /api/platforms/{id}/export` | 가져오기·내보내기 |
| `GET /api/guidelines` · `GET /api/guidelines/overrides?name=` | 전역 가이드라인 목록, 덮어쓴 곳 |
| `POST /api/guidelines/{name}/reset` | 기본 가이드라인으로 되돌리기 |
| `GET /api/vault` · `POST /api/vault` · `DELETE /api/vault/{name}` | 인증 정보 목록(가린 값)·추가·지우기 |
| `POST /api/vault/{name}/reveal` | 비밀번호 확인 후 값 하나 보기 |
| `POST /api/vault/password` | 비밀번호 바꾸기 |
| `GET /api/storage` · `POST /api/storage/clear-cache` | 저장 공간, 캐시 비우기 |

LLM 연결 API는 03-llm, 금고 초기화는 [00-shell](00-shell.md)의 `POST /api/auth/reset`.

## 단계

- **0단계**: 일반(언어, 자동 저장), 금고(추가·보기·지우기, 비밀번호 바꾸기, 초기화), 정보.
- **1단계**: 플랫폼 프리셋 전체, 전역 가이드라인, 저장 공간, 자동 잠금, 이력 정리 기준.
- **2단계**: LLM 연결(03-llm과 함께).
- **5단계**: 태그 사전.
- **7단계**: 이미지 생성 연결.

## 정할 것

- 앱에 포함할 기본 가이드라인(압축, 이미지 프롬프트, 관계 검사, 규모별 뼈대 작성)의 내용은 각 기능 문서를 쓸 때 정한다.
