# 현재 구현 상태와 남은 작업

기준: 2026-09-23 develop 코드와 사용자 결정. **구현**은 코드 존재, **확인**은 실제 실행·사용자 확인, **미검증**은 근거 없음이다. 우선순위는 사용자 확정 표시가 없으면 제안이다.

## 사용 가능 범위

- 사용자가 결과를 보며 하는 **개인 소규모 제작은 가능**. 2026-09-22 사용자 실사용 확인으로 P0 제작 흐름 점검을 종료했다.
- **무인 대량 운영은 준비되지 않았다.** 대량 저장·상태 전이·복구는 모의 Provider 검사 근거이며 수천 장의 GPU·VLM 연속 실행 근거는 없다. 제작 계획의 8개 실행 창·32개 묶음 분할은 동시성·요청 크기 제한일 뿐 처리량 보장이 아니다.
- 운영 기준: 작은 계획부터 시작하고 묶음 결과·저장 이미지·디스크 여유를 확인한 뒤 다음 계획을 진행한다. 묶음 `failed`·`incomplete`·`error`는 작업 완료와 품질 합격을 구분해 사람이 처리한다.

## 구현됨

- Core/Generation/Validation REST, 작업 상태·큐·취소·공유 GPU 조정, 멱등 접수·재시작 복구.
- 작품 > 캐릭터(외형) > 의상(상의·하의·액세서리), 전역 조각(사용자 카테고리·전역 고유 번호), 프롬프트 합성·미리보기, 공통 적용 프롬프트(본문만 전체에 추가).
- 제작 계획: 의상 체크 트리 × 조각 체크 트리, 총 장수·예정 목록, 생성만/단일 검사/단일+묶음 검사 선택(미검사는 합격 아님). Seed -1 이미지별 무작위, 실제 사용값 Core 기록.
- 단일/묶음 검사, 재생성(수동·자동 상한), 기준 revision·결과 이력, Alpha 단계에 따른 투명도 요구 전달.
- Anima·다중 LoRA, Upscale(모델 목록 선택·예상 해상도)·Detailer·Censor·Alpha·Encode, Core 등록 이미지의 독립 후처리.
- Frontend: 캐릭터 관리/이미지 생성 분리, 진행·검토·갤러리·이미지셋, 설정(Core 연결 통합·Preset·Profile/Provider), 반응형 배치.
- 연결: Access JWT 자동 연결(Core 검증), 로컬 Bearer fallback, 전경 일괄 실행기·안전 종료, 고정 Named Tunnel.
- Python Client·CLI(작업·검증·재생성·취소·그룹 검사·설정), Discord 봇([명세](discord.md)).

## 확인·미검증 구분

| 범위 | 확인됨 | 미검증 |
| --- | --- | --- |
| 생성·후처리 | Anima 1024 → UltraSharp 1536, PNG/WebP, 주요 후처리 실행 | Detailer 개선·Censor 누락·Alpha 경계 품질 |
| VLM 검사 | 제한된 이미지의 단일·묶음 실행 | 대표 세트 오탐/미탐, 처리량 |
| 복구 | 모의 Provider·실제 SQLite/TCP/프로세스 재기동, 단일 항목 실제 GPU 복구 | ComfyUI 자체 재시작, VLM 실행 중 장애, OOM·외부 ComfyUI 경합, 장기 실행 |
| Frontend | 사용자 실사용(P0), 브라우저 자동 검사 | 물리 모바일 기기(터치·키보드·Access 재로그인), 스크린리더 |
| 원격 | Access 경계(익명·토큰 조합), Worker→Bridge 경로 | 외부 브라우저의 무토큰 자동 연결 명시 기록, 원격 Generation/Validation 실행 |
| 실행기 | 코드·검사 | 운영 파일럿의 실제 Ctrl+C 종료·재실행 |

수락 불명(원래 POST 지연 중 키 조회가 먼저 도착 등)은 자동 정리하지 않고 명시 오류·운영자 확인으로 남긴다. 실행 불명을 재생성이나 GPU 강제 해제로 해결하지 않는다.

## 남은 작업

### 확정 순서 (2026-09-22~23 사용자 결정)

1. P1 후속: 설정/모바일 추가 보완 → 백업/복원(O2) → 장애·GPU 경합 검증(R4).
2. 운영·문서: 기준점 확보 → 현행 요약과 이력 분리 → Tunnel 정리 → 동작 불변 리팩토링 → 운영 제어판·F/E 현황판(O5) → README·사용자 문서 → 웹 매뉴얼 → UI/UX 개선(장기).

두 순서의 상호 순서는 기록되어 있지 않다(확인 필요).

## 확인이 필요한 사항

- 외부 브라우저 Access 무토큰 자동 연결의 실제 확인 여부.
- Discord 두 번째 서버의 재시작 후 권한·실제 응답 확인 여부.
- 2026-09-23 순서의 "Tunnel 정리" 범위(구 Tunnel 자원 정리인지, O5 편입인지).
- P1 후속 순서와 2026-09-23 운영·문서 순서의 선후.
