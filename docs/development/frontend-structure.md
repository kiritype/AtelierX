# Frontend 전체 구성과 화면 연결

기록일: 2026-09-13. 사용자가 제시된 구성을 승인하고 그대로 진행하도록 지시했다. **상단 4개 메뉴·하위 화면 역할·기본 배치·공통 이동 원칙은 합의 사항**이다. 이 문서는 Frontend 구현 완료 또는 미정 API의 구현 완료를 뜻하지 않는다. 색상·크기·단축키·Framework는 이번 합의에 포함하지 않는다. 상세 상호작용은 [제작 화면 상세](frontend-production-screen.md)의 구현 초안으로 구분한다.

## 합의한 상단 구성

| 상단 메뉴 | 하위 화면·영역 | 핵심 역할 |
| --- | --- | --- |
| 제작 | 작품/캐릭터/의상 탐색·관리, 프롬프트 편집, 생성·후처리 설정, 단일/일괄 생성 | 만들 내용을 준비하고 Core에 실행 요청 |
| 갤러리 | 전체 이미지, 분류별 이미지, 이미지 상세, 그룹 검토·기준 관리 | 생성 결과 및 단일·묶음 판정 검토 |
| 작업 현황 | 진행 중·대기, 일괄 작업 상세, 완료·실패·취소 이력 | 작업 추적·취소·오류 확인 및 결과 이동 |
| 설정 | 전역 프롬프트, 생성/후처리 Preset, 검사 Profile·AI Provider, 자동 재생성, 서비스 연결 | 반복 사용하는 설정과 연결 관리 |

하위 항목은 기능 구분이다. 모두 별도 페이지나 상단 탭으로 늘리지 않는다. 이미지 상세·작업 상세는 목록에서 진입하고, 설정 하위 구분은 설정 화면 안에서 탐색한다. 검증은 별도 상단 메뉴로 분리하지 않고 이미지·그룹 상세에 배치한다.

## 제작의 기본 배치

```text
┌──────────────────────────────────────────────────────────────────┐
│ 제작                 갤러리             작업 현황             설정 │
├───────────────┬──────────────────────────────┬───────────────────┤
│ 작품          │ 현재 작품 / 캐릭터 / 의상     │ 생성 설정         │
│ └ 캐릭터      │                              │ 모델·Preset       │
│   └ 의상      │ 저장할 프롬프트 편집          │ 다중 LoRA + / -   │
│               │ 외형 / 상의 / 하의           │ 해상도·Seed 등    │
│ 추가·편집     │                              │                   │
│ 보관          │ 이번 생성                    │ 후처리·검증 선택  │
│               │ 단일 / 일괄                  │                   │
│               │ 구도·표정·자세·상황           │ 적용값 요약       │
│               │ 최종 프롬프트 미리보기        │ 생성 실행         │
├───────────────┴──────────────────────────────┴───────────────────┤
│ 접수 상태 / 최종 결과 요약         작업 상세로 이동 · 갤러리로 이동 │
└──────────────────────────────────────────────────────────────────┘
```

작품은 분류이며 생성 프롬프트에 삽입하지 않는다. 캐릭터 Negative는 캐릭터 편집에, 외형·상의·하의(풋웨어 포함)는 의상 편집에 둔다. 액세서리 별도 구분은 두지 않는다. 표정·자세·구도·상황은 이번 생성 입력이며 저장된 의상 원문과 혼동하지 않는다. 전역 Prompt는 설정에서 편집하고 제작에서는 적용값과 설정 이동을 제공한다.

실행을 접수해도 제작 화면을 유지한다. 접수 상태와 최종 결과 요약은 작업 현황·갤러리 상세로 연결하며 작업 완료를 기다리는 동안 편집 전체를 잠그지 않는다. 진행 중 이미지 미리보기는 기존 보류 범위를 유지한다.

## 갤러리의 기본 배치

왼쪽에는 작품 > 캐릭터 > 의상 분류 탐색, 가운데에는 필터·정렬·선택과 이미지 목록을 둔다. 이미지 선택 시 상세 또는 확대 보기를 연다. 전체 목록과 그룹별 목록의 선택 범위를 구분한다.

이미지 상세는 최종 이미지, 실제 생성 Prompt·설정, 단일 검증, 묶음 검증·기준 revision, 재검증·수동 재생성 및 이력을 연결한다. 그룹 검토는 대표·보조와 대상 비교를 함께 보여 준다. 시스템 후보는 사용자 확정 전까지 후보이며 기준 교체 뒤 재검증 여부를 확인한다. v9의 기준 충돌은 대상 결함과 구분하고 대상 미비교 상태를 유지한다.

삭제·내보내기는 필요한 API·데이터 보존 기준을 구체화한 뒤 연결한다. 화면 구성이 승인됐다는 이유로 미지원 API나 임의 파일 접근을 추가하지 않는다.

## 작업 현황과 설정

작업 현황은 개별 Task와 일괄 작업을 구분하고 상태·진행 단계·대기 사유·자동 재생성 횟수·오류 코드를 표시한다. 작업 상세에서 취소하거나 해당 제작 그룹·결과 이미지로 이동한다. Backend가 제공하지 않는 퍼센트 진행률을 만들어 표시하지 않는다.

설정은 전역 값을 편집한다. 자동 재생성 on/off와 기본 상한 5회, Provider와 단일/묶음 검사 Profile, 생성/후처리 Preset을 제공한다. 과거 실행 상세는 현재 설정이 아니라 당시 snapshot을 표시한다. 모델 다운로드·AI Draft 등 후속 기능은 현 설정 메뉴가 있다고 해서 준비된 기능으로 표시하지 않는다.

## 화면 간 이동과 공통 상태

| 출발·동작 | 도착·유지할 문맥 |
| --- | --- |
| 제작에서 실행 접수 | 현재 제작 화면 유지, 접수한 Task/Batch 링크 제공 |
| 제작에서 결과 보기 | 해당 그룹 또는 결과 이미지 상세, 전체 갤러리로 잘못 확장하지 않음 |
| 작업 상세에서 결과 보기 | 해당 작업의 이미지와 실행 이력 |
| 갤러리에서 생성 설정 확인 | 이미지에 저장된 당시 Prompt·설정 읽기 전용 표시 |
| 갤러리에서 재검증/재생성 | 선택 대상과 현재 기준 확인, Core의 기존 요청 API 호출 |
| 제작에서 전역 설정 이동 | 돌아왔을 때 작품·캐릭터·의상 선택과 편집 문맥 복원 |
| 메뉴 이동 | 메뉴별 분류 선택·필터 유지, 미저장 편집이 있으면 이동 전 안내 |

합격/불합격, 비교 불충분, 실행 오류, 미검증을 구분한다. 기준 변경 전 결과와 현재 기준의 유효한 결과를 섞지 않는다. 이미지가 없는 초기 상태·연결 실패·목록 없음·권한 오류를 빈 성공 목록처럼 처리하지 않는다.

## 구현 책임과 후속 순서

Frontend는 UI 상태와 사용자 입력·표시를 담당하고 Shared API Client로 REST를 호출한다. Core의 Prompt 조합·그룹 snapshot·생성/검증/재생성 조정·집계를 복제하지 않는다. 별도 BFF를 추가하지 않는다. Backend → Shared Client 기반 CLI → Frontend의 기존 개발 순서와 이번 화면 분석을 구분한다.

다음 상세 단위는 [제작 화면](frontend-production-screen.md)이며, 메뉴별 기존 API·공백·개발 수용 기준은 [API 대조표](frontend-menu-api-map.md)에 정리한다. 일반 조회·UI 상세를 새 ADR 승인 질문으로 분할하지 않는다. 삭제·외부 실행·데이터 보존 등 기존 정책을 바꾸는 사항은 따로 구분한다.

근거: 사용자 메뉴 구성 승인, [ADR-0021](../architecture/adr/0021-core-domain-and-image-groups.md), [ADR-0022](../architecture/adr/0022-prompt-composition.md), [ADR-0023](../architecture/adr/0023-negative-prompt-sources.md), ADR-0007~0020의 검증·사용자 확인 정책, [요구사항 대조](../requirements/module-feature-comparison.md), [기능/API 분석](frontend-requirements-analysis.md).


## 2026-09-13 Client·CLI 및 화면 상세 후속

[Shared Client·CLI 첫 구현](shared-client-cli.md)은 Core 조회 연결 범위와 사용법을 기록한다. [갤러리 상세 초안](frontend-gallery-screen.md)과 [작업 현황 상세 초안](frontend-jobs-screen.md)은 사용자 검토용 배치·상태·동작·수용 기준이다. 화면 코드는 아직 구현하지 않았다.


[설정 화면 상세 초안](frontend-settings-screen.md): 사용자 요청한 좌측 카테고리·우측 설정, 핵심 섹션과 고급 접기, 저장·revision 충돌·동기화 상태를 정리했다. 화면 구현 전 검토용이다.


## 2026-09-13 파일럿 구현 반영

사용자 후속 지시로 네 메뉴의 F/E 파일럿을 구현했다. 앞의 화면 코드 미구현 표기는 [현재 실행·검증 범위](frontend-pilot.md)로 갱신한다. 상세 초안 전체가 모두 구현·시험된 것은 아니며 JSON 입력과 후속 검증 범위를 보고서에 구분했다.
