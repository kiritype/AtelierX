# 검증 범위와 출시 상태

AtelierX는 아직 테스트 단계(0.0.x)입니다. 이 안내는 확인된 범위를 구분해 사용자가 기능 상태를 판단하도록 돕습니다. 버전마다 바뀐 점은 [바뀐 점](../changelog.md)에 있습니다.

## 확인된 내용

- Windows x64 포터블 패키지를 개발 PC에서 새 앱 데이터로 실행했습니다.
- 네이티브 창이 열리고 닫히는 동작을 확인했습니다.
- Ollama Cloud 연결에서 모델 목록, 합성 응답, 스트리밍 동작을 확인했습니다.
- 작성·편집은 외부 이미지 도구 없이 사용할 수 있고, 앱 데이터는 포터블 폴더에 저장되는 구조입니다.
- 0.0.3 시험판으로 개발 PC에서 에이전트 패널(실제 LLM), 이미지 생성·검수·업스케일, 대화 테스트와 페르소나를 확인했습니다. 이 설명서의 캡처가 그때 찍은 것입니다.

## 아직 검증되지 않은 범위

- Vertex AI 연결은 출시 환경에서 검증하지 않았습니다. Vertex OAuth 토큰은 만료 시 직접 갱신해야 하며 자동 갱신되지 않습니다.
- 깨끗한 별도 Windows PC에서 설치·업데이트·복구 절차를 검증하지 않았습니다.
- 실제 이미지 생성 전체 흐름과 모든 ComfyUI 노드·모델 조합을 출시 기준으로 검증하지 않았습니다.
- LoRA 학습 도구 설치부터 학습 완료까지의 전체 조합을 별도 PC에서 검증하지 않았습니다.

개발 PC에서의 성공은 다른 PC의 실행, 계정 설정, GPU·드라이버 조합을 보장하지 않습니다. 이미지와 학습 기능은 외부 프로그램·모델의 버전 및 시스템 요구사항을 따릅니다.
