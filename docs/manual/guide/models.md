# 모델

이미지 생성 서버(ComfyUI)가 가진 모델·LoRA를 한곳에서 봅니다. 작품 상단 **이미지** 메뉴 → **모델**에서 엽니다. 이미지 생성 서버에 연결되어 있어야 목록이 나옵니다.

## 화면

- 위쪽 막대: **찾기**(이름·기반 모델·트리거 단어), 거르기(종류, 계열, 출처, 기반 모델), **나란히 보기**, **새로 고침**
- 가운데: 모델 카드. Stability Matrix로 받은 파일은 그 미리보기가 보입니다. 카드에는 이름, 파일 이름, 종류(체크포인트·디퓨전 모델·LoRA·텍스트 인코더·VAE·업스케일 모델), 계열(Anima·SDXL·IL), 출처가 보입니다.
- 오른쪽: 카드를 누르면 파일 위치, 크기, 출처, Civitai 정보, 기반 모델, 트리거 단어, 라이선스가 보입니다. 트리거 단어는 누르면 복사됩니다.

새로 넣은 파일이 안 보이면 ComfyUI에서 모델 목록을 새로 고친 뒤 **새로 고침**을 누릅니다.

## 출처

- **Civitai**: Stability Matrix로 받아 정보 파일(`.cm-info.json`)이 함께 있거나, 이 화면에서 조회한 파일
- **학습**: 이 앱으로 학습한 LoRA(ComfyUI의 `atelierx` 폴더) → [LoRA 데이터셋과 학습](lora.md)
- **출처 모름**: 정보가 없는 파일. **Civitai 정보 조회**로 찾아볼 수 있습니다.

## Civitai 정보 조회

오른쪽 아래 **Civitai 정보 조회**를 누르면 파일의 해시(SHA256)를 계산해 Civitai에서 찾습니다. 키는 필요 없습니다.

- 찾으면 모델·판 이름, 작성자, 기반 모델, 트리거 단어, 라이선스(상업 이용·파생물·출처 표기 조건)를 보여 주고 기억합니다.
- 큰 파일은 해시 계산에 몇 초에서 수십 초 걸립니다. 한 번 계산한 해시는 기억해 두므로 다시 조회할 때는 바로 끝납니다.
- Civitai에 없는 파일(직접 만들었거나 올라오지 않은 파일)은 "찾지 못했습니다"로 표시됩니다.
- 조회한 정보는 앱 데이터에만 저장합니다. 모델 폴더에는 아무것도 쓰지 않습니다.

## 찾기

**찾기** 탭에서 Civitai의 모델을 찾습니다.

1. 검색어를 넣고 **찾기**(또는 Enter)를 누릅니다. 종류, 기반 모델, 정렬을 고를 수 있습니다. 처음에는 Anima용 LoRA를 평가 높은 순으로 보여 줍니다.
2. **NSFW 포함**은 기본으로 꺼져 있습니다. 꺼 두면 성인 모델과 성인 등급 미리보기 그림이 보이지 않습니다. 마지막 선택을 기억합니다.
3. 카드를 누르면 **받기** 탭으로 넘어가 그 모델을 읽습니다. 판과 파일을 확인하고 받으면 됩니다.
4. 아래 **더 보기**로 다음 결과를 이어 봅니다.

## 받기

**받기** 탭에서 Civitai의 모델을 받습니다. 많은 파일이 Civitai API 키가 있어야 받아지므로, 먼저 설정 → 이미지 → **모델 받기 (Civitai)**에 키를 넣어 두세요. 키는 Civitai 계정 설정 → API Keys에서 만들고, 앱 금고에 암호화해 저장됩니다.

1. Civitai 모델 페이지 주소(또는 다운로드 주소, 모델 번호)를 붙여 넣고 **읽기**를 누릅니다.
2. 모델 이름, 종류, 작성자, 라이선스와 판 목록이 보입니다. **판**을 고르면 그 판의 파일·크기·트리거 단어가 보입니다.
3. 라이선스(상업 이용·파생물 조건)를 확인한 뒤 파일의 **받기**를 누릅니다.
   - 파일은 ComfyUI가 읽는 그 종류의 폴더 아래 계열 폴더(`anima`, `sdxl`)에 들어갑니다. **하위 폴더**에 다른 이름을 적으면 그곳에 넣습니다.
   - Anima 기반 모델은 디퓨전 모델 폴더에 들어갑니다.
4. **받기 목록**에서 진행률을 봅니다. 한 번에 하나씩 받고, 받기 전에 디스크 공간을 확인합니다.
   - 끊기거나 앱을 껐다 켜면 **이어 받기**로 남은 부분만 받습니다.
   - 다 받으면 Civitai의 해시와 비교해 확인합니다. 받은 모델은 **내 모델**에서 출처 "Civitai"로 보입니다.
   - "API 키가 있어야 받을 수 있습니다"가 나오면 키를 넣고 **이어 받기**를 누릅니다.

### 직접 받은 파일 넣기

브라우저로 받은 파일을 ComfyUI 폴더로 옮길 때 씁니다. 키가 없어도 됩니다.

1. 받기 탭 아래 **직접 받은 파일 넣기**를 펼칩니다. 다운로드 폴더의 모델 파일이 보입니다(다른 폴더를 적을 수도 있음).
2. 파일의 **확인**을 누르면 해시로 Civitai에서 찾아 종류와 계열을 제안합니다.
3. 종류와 하위 폴더를 확인하고 **옮기기**를 누릅니다. 파일이 옮겨지고, 찾은 Civitai 정보가 함께 저장됩니다.

## 계열 지정

생성 화면은 고른 계열(Anima / SDXL·IL)의 모델·LoRA만 보여 줍니다. 계열은 다음 순서로 자동으로 정해집니다.

1. 폴더 이름(`anima/`, `sdxl/` 아래에 있으면)
2. 직접 지정한 값
3. Civitai 정보 조회로 알게 된 기반 모델
4. Stability Matrix 정보 파일의 기반 모델
5. 파일 헤더

자동으로 정해지지 않거나 틀렸으면 오른쪽의 **계열**에서 Anima 또는 SDXL·IL을 고릅니다. **자동으로 정함**을 고르면 직접 지정을 지웁니다. 옆에 어떻게 정했는지가 보입니다.

예전 버전에서는 이 표가 설정 → 이미지에 있었습니다. 설정에는 이제 공유 모델 폴더 경로만 남아 있습니다.
