# 샘플 작품 따라 하기

이 연습에서는 샘플 복사본의 파일 하나를 고쳐 저장하고, 실제 연결이 준비된 경우 대화 테스트와 작품 내보내기를 이어서 합니다. 앱의 기본 **로컬 LLM** 주소는 `http://127.0.0.1:1234/v1`이며, 호환 서버가 실행 중이지 않으면 테스트 응답을 받을 수 없습니다. 기본 UI에는 모의 제공자를 고르는 일반 설정 항목이 없습니다.

## 1. 샘플 복사본 열기

1. 잠금을 푼 뒤 작품 선택 화면에서 **샘플**을 누릅니다.
2. 샘플 목록의 한 작품을 선택합니다. 샘플은 작품으로 복사되어 열립니다.
3. 왼쪽 파일 트리에서 메인 프롬프트 파일을 클릭합니다.

## 2. 파일을 수정하고 저장

1. 본문 끝에 테스트용 문장을 한 줄 추가합니다. 예를 들어 `대화는 차분하고 짧은 문장으로 이어 간다.`라고 입력합니다. 이 문장은 연습용이며 작품 설정에 맞게 바꿔도 됩니다.
2. **Ctrl+S**를 눌러 저장합니다. 탭의 변경 표시가 사라지고 저장 오류 배너가 없는지 확인합니다.
3. 왼쪽 트리에서 캐릭터 파일도 열어 상단의 **종류**, **ID**, **키워드**를 살펴봅니다. 내용을 바꾸지 않고 확인만 해도 됩니다.

## 3. 대화 테스트

1. 별도 OpenAI 호환 로컬 서버가 실행 중인지 확인합니다. 서버에서 모델을 불러오고, 제공자 주소 및 모델 이름을 준비합니다. 연결 준비 방법은 [LLM 연결](connections.md)에 있습니다.
2. 작품 상단에서 **테스트**를 누릅니다. 시작 상황이 있으면 테스트할 항목을 고릅니다.
3. 입력란에 `오늘은 무엇을 하고 있었어?`라고 보내 봅니다. 이 문장은 가상의 예시 입력입니다.
4. 응답이 도착하면 메시지와 화면의 맥락/불러온 항목 정보를 확인합니다. 기대되는 성공은 선택한 시작 상황과 메인 프롬프트가 요청에 반영되고, 연결 모델의 응답이 대화에 추가되는 것입니다.

연결 오류가 나면 **← 작업으로** 돌아가 설정 → LLM에서 로컬 주소, 기본 모델을 확인하고 **모델 목록**, **연결 시험**을 차례로 실행하세요. 기본 주소의 서버를 준비하지 않았다면 실제 LLM 대화 단계는 건너뛰고 편집·내보내기 흐름만 익힐 수 있습니다. 모의 응답을 기본 기능처럼 선택할 수 있다고 가정하지 마세요.

## 4. 작품 내보내기

1. **← 작업으로** 돌아옵니다.
2. 작품 메뉴에서 **내보내기**를 선택하고 쓰기 권한이 있는 빈 폴더를 지정합니다. 예: `D:\AtelierX-export\practice`.
3. 미리보기의 포함 파일과 제외 파일을 확인합니다. 폴더에 기존 파일이 있다면 기존 내용을 확인합니다. 파일명 충돌이 있으면 충돌 표시를 해결해야 실행할 수 있습니다.
4. 연습에서는 기본으로 선택된 **스냅샷**을 유지하고 **내보내기**를 누릅니다.
5. 완료 알림을 확인한 뒤 대상 폴더에 메인·시작 상황·사용 중인 로어북 등 예상 파일이 생성됐는지 확인합니다.

## 성공 확인과 다음 단계

편집 탭에 저장 표시가 있고, 대상 폴더에서 미리보기 포함 목록의 파일이 보이면 이 연습은 완료입니다. 대화 응답 성공은 별도 LLM 서버 연결이 있을 때만 기대할 수 있습니다. AI 제안 적용이나 압축은 [AI 도구와 결과 검토](ai-tools.md), 외부 연결은 [LLM 연결](connections.md)을 참고하세요.
