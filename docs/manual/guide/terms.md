# 용어와 저장 범위

같은 화면에서 보이는 값도 원본 프리셋, 현재 입력, 완료된 결과에 따라 의미가 다릅니다. 무엇을 바꾸는지 확인하고 저장·적용·생성을 구분해 사용하세요.

## 자주 쓰는 용어

| 용어 | 뜻 | 자세히 |
|---|---|---|
| 작품 | 원고·등장인물·설정과 작업 기록을 묶는 작업 단위 | [작품 관리](works.md) |
| 메인 프롬프트 / 시작 상황 / 로어북 | 기본 지시, 대화 시작 문구, 조건에 따라 참고할 설정 파일 | [파일 편집](editing.md) |
| 에이전트 제안 / 채택 | AI가 제안한 내용과, 검토 후 실제 파일에 반영하는 동작 | [에이전트](agent.md) |
| 생성 서비스 / 모델 계열 / 모델 | 실행할 제공자, 설정·워크플로를 공유하는 분류, 실제 사용할 모델 | [이미지 환경](image-setup.md), [모델 관리](models.md) |
| 그림체 프리셋 | 서비스·모델·LoRA·생성 설정·artist 태그를 다시 쓸 수 있게 저장한 묶음 | [그림체 프리셋](style-presets.md) |
| 프롬프트 라이브러리 | 공통 문구·표정·구도·의상 조각을 관리하는 곳 | [프롬프트 라이브러리](image-library.md) |
| Positive / Negative | 결과에 포함할 내용과 피할 내용을 서비스 문법으로 입력하는 칸 | [단일 생성](single-generation.md) |
| 시드 | 생성에 사용하는 난수의 시작값. 같은 값만으로 모든 환경에서 동일한 이미지를 보장하지는 않음 | [단일 생성](single-generation.md) |
| LoRA / 모델 강도 / CLIP 강도 | 모델에 추가하는 파일과, 이미지 모델·텍스트 인코더에 각각 적용하는 세기 | [모델 관리](models.md), [그림체 프리셋](style-presets.md) |
| 생성 대기열 | 접수된 이미지 작업의 대기·실행·완료·실패 상태를 보는 곳 | [이미지 생성 개요](generation.md) |
| 판정 / 채택 | 이미지 검토 결과와, 캐릭터·의상·표정 조합에 사용할 한 장의 선택 | [갤러리](gallery-export.md) |
| 그림체 탐색 / Elo | 여러 후보를 비교하는 기능과 해당 탐색 안의 상대적 선호 점수 | [그림체 탐색](style-explorer.md) |

## 무엇이 어디에 적용되나요?

| 대상 | 범위와 변경 시점 |
|---|---|
| 앱 설정 | 언어·테마·연결 등 앱 전체에 적용. 작품 설정과 구분 |
| 작품 설정·원고 | 현재 작품에 적용. 저장된 파일과 기록에서 확인 |
| 그림체 프리셋 | 모든 작품이 함께 사용. 프리셋 편집 후 저장하면 원본 설정이 바뀜 |
| 프롬프트 조각 | 전역 또는 작품 범위. 현재 범위를 확인하고 저장 |
| 생성 화면의 현재 입력 | 다음 생성 요청에 사용할 값. 프리셋을 적용한 뒤 여기에서 바꿔도 원본 프리셋을 자동 수정하지 않음 |
| 결과의 기록된 설정 | 해당 이미지 생성 당시의 값. 현재 입력이나 원본 프리셋을 고쳐도 과거 기록은 바뀌지 않음 |
| 탐색의 기준 프리셋 | 탐색을 만들 때 복사한 설정. 원본을 나중에 수정·삭제해도 그 탐색은 당시 설정을 사용 |

단일 생성에서 그림체·캐릭터·표정·구도를 적용한 뒤에는 **출처별 프롬프트**와 **조합된 프롬프트 확인**을 대조하세요. 직접 입력한 문구와 재료에서 가져온 문구를 구분할 수 있습니다.

## 비슷한 버튼의 차이

| 동작 | 결과 |
|---|---|
| 프리셋 저장 | 재사용할 설정을 저장. 이미지 생성은 별도 |
| 프리셋 적용 | 생성 화면에 설정을 전달. 생성 버튼은 별도로 누름 |
| 결과 설정 불러오기 | 당시 입력과 설정을 생성 화면에 복원. 새 작업을 제출하지 않음 |
| 같은 시드로 재생성 / 새 시드로 변형 | 기록된 설정을 사용해 새 생성 작업을 제출 |
| 이미지 통과 | 사람이 통과로 판정. 캐릭터 조합의 이미지라면 해당 조합에 채택 |
| 작업 사본 삭제 | 이미지 도구가 보관한 사본을 삭제. 갤러리 원본과 구분 |

저장 위치와 옮기는 방법은 [유지 관리](maintenance.md)를 보세요. 앱 밖으로 이미지를 공유할 때는 [이미지 내보내기](gallery-export.md)에서 생성 정보 포함 여부를 확인할 수 있습니다.
