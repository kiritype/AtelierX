# 바뀐 점

0.0.7부터는 도움말 → **업데이트 확인**에서 앱 안에서 바로 업데이트할 수 있습니다. 새 패키지를 직접 받았다면 이전 앱 폴더의 `config`, `state`, `data`, `output` 폴더를 새 폴더로 옮겨 쓰세요. 자세한 절차는 [유지 관리](guide/maintenance.md)에 있습니다.

## 0.3.0

이번 버전은 데이터 형식이 바뀌는 MINOR 버전입니다. 처음 실행할 때 예전 생성 프리셋과 화풍 조각을 그림체 프리셋으로 한 번 옮깁니다(아래). 업데이트 전에 **전체 백업**을 해 두는 것을 권합니다.

### 새 기능

- **그림체 프리셋**: 생성 프리셋과 화풍 조각을 하나로 합쳤습니다. 그림체 프리셋 하나에 서비스(ComfyUI·NovelAI·PixAI)와 모델 계열, 생성 설정(모델·샘플러·크기·LoRA 등), **artist 태그**(그림체를 정하는 작가·앞머리 태그와 피할 태그), 사용자 태그, 기본 공통 프롬프트가 들어갑니다. 이미지 메뉴 → **준비** → **그림체 프리셋** 화면에서 카드로 찾고(서비스·계열·태그·모델·LoRA 거르기), 2~4개를 나란히 비교하고, 생성 화면으로 보냅니다. → [그림체 프리셋](guide/style-presets.md)
  - **미리보기**: 프리셋마다 같은 프롬프트·같은 시드로 한 장씩 만들어 그림체를 나란히 비교합니다. 설정이 바뀌면 "오래됨"으로 표시하고, 없거나 오래된 미리보기를 한꺼번에 만들 수 있습니다(ComfyUI 프리셋).
  - **공유**: 체크한 프리셋(또는 전체)을 ZIP 하나로 내보내고 가져옵니다. 미리보기가 함께 가고, 모델·LoRA 파일은 넣지 않는 대신 파일 이름·해시·Civitai 주소를 적어 받는 쪽에 없는 파일을 알려 줍니다. 가져올 때 프리셋마다 추가·바꾸기·다른 id로 추가·건너뛰기를 고릅니다.
- **모델 화면**: 이미지 메뉴 → **준비** → **모델**. 이미지 생성 서버의 체크포인트·디퓨전 모델·LoRA·텍스트 인코더·VAE·업스케일 모델을 카드로 보고, 계열(Anima·SDXL·IL)을 여기서 정합니다. → [모델](guide/models.md)
  - **Civitai 정보 조회**: 파일 해시로 Civitai에서 모델·판 이름, 기반 모델, 트리거 단어, 라이선스를 찾아 기억합니다(키 필요 없음).
  - **찾기**: Civitai 모델을 검색어·종류·기반 모델·정렬로 찾습니다. **NSFW 포함**은 기본으로 꺼져 있습니다.
  - **받기**: Civitai 주소를 붙여 넣어 판과 파일을 고르고 받습니다. 한 번에 하나씩, 끊기면 이어 받고, 끝나면 해시로 확인합니다. 키가 필요한 파일은 설정 → 이미지 → **모델 받기 (Civitai)**에 키를 넣습니다(금고에 암호화). 브라우저로 받은 파일은 **직접 받은 파일 넣기**로 옮깁니다.
- **한 번에 업스케일·디테일러**: 생성 설정에 모델 보정(shift, Anima), LoRA 켜기·끄기, 업스케일 후 다시 그리기, 부위별 디테일러(얼굴·눈·입·손)를 더했습니다. 켜면 생성 한 번에 차례로 처리합니다. → [이미지 생성](guide/generation.md)
- **표정마다 배경과 의상**: 구도 조각이 **구도·배경** 조각이 되어 배경 태그를 담고, **의상 없음**을 켤 수 있습니다. 표정이 고른 구도·배경에 따라 표정마다 배경과 의상이 달라집니다(예: 샤워 표정은 욕실 배경에 의상 없이). 새로 만드는 라이브러리는 구도 조각에 단색 배경을 넣고 공통 **단색 배경**을 기본으로 끕니다. 쓰던 라이브러리는 그대로이니 설명서를 보고 옮기세요. → [프롬프트 라이브러리](guide/image-library.md)
- **프롬프트 메모**: 태그 칸에 `#`로 시작하는 메모를 남길 수 있습니다. 조각에는 남고 생성 요청·기록에는 들어가지 않습니다. → [프롬프트 라이브러리](guide/image-library.md)
- **프롬프트 라이브러리 내보내기·가져오기**: 표정·구도·공통·공용 의상 부위 목록에서 체크한 조각(또는 전체)을 파일 하나로 내보내고 다른 PC에서 가져옵니다. 가져올 때 조각마다 새 항목·이미 있음과 바뀌는 내용을 보고 추가·덮어씀·건너뜀을 고르며, 넣을 곳(전역·작품)을 정합니다. → [프롬프트 라이브러리](guide/image-library.md)
- **섹션 없이 이미지 프롬프트 변환**: 캐릭터 문서에 `## 외모`·`## 의상` 구역이 없어도 됩니다. → [캐릭터 이미지 설계](guide/character-images.md)
  - **본문 전체 변환**: 문서 전체에서 이 인물의 지금 외모·의상을 찾아 태그와 근거 문장으로 제안합니다. 이미 있는 의상은 같은 이름으로 짝지어 갱신하고 새 옷만 더합니다.
  - **범위 지정 변환**: 본문에서 글을 고르고 우클릭(또는 Alt+P) → **이미지 프롬프트로** → 외모·의상(기존 의상 또는 새 의상)·외모에 범위 추가. 고른 글만 그 부분의 태그로 바꿉니다.
  - 근거 문장과 고른 범위를 원문으로 남겨, 그 글이 바뀐 부분만 **원문 변경됨**으로 표시합니다. 고른 범위로 만든 부분과 직접 고친 부분은 본문 전체를 다시 변환해도 기본으로 유지됩니다.
- **편집기 우클릭 메뉴**: 본문에서 우클릭(또는 Alt+P)하면 잘라내기, 복사, 에이전트에 첨부(Ctrl+L) 메뉴가 열립니다. → [파일과 편집기](guide/editing.md)
- **이미지 도구 → 생성 정보 표**: 그림 파일에 남은 생성 정보를 표로 보여 줍니다. 어느 도구(ComfyUI, WebUI·Forge, NovelAI, PixAI, AtelierX)로 만들었는지, 모델·LoRA·샘플러·시드 같은 설정, 그 파일이 이 PC에 있는지를 알려 줍니다. 보기만 하고 프리셋을 만들지는 않습니다. → [이미지 도구](guide/image-tools.md)

### 바뀐 점

- **학습한 LoRA는 앱 폴더에**: 학습한 LoRA를 ComfyUI 폴더가 아니라 앱의 `output/loras/`에 두고, ComfyUI의 LoRA 폴더에는 `atelierx` 폴더 연결(정션)만 만듭니다. ComfyUI를 다시 설치해도 LoRA가 남습니다. 설정 → 이미지 → LoRA 학습의 **ComfyUI 연결**에서 상태를 보고 다시 연결하며, 예전처럼 ComfyUI 안에 있던 LoRA는 **AtelierX로 옮기기**로 옮깁니다. → [LoRA 데이터셋과 학습](guide/lora.md)
- **마스터 비밀번호 8자 이상**: 새로 정하거나 바꾸는 비밀번호는 8자 이상입니다. 더 짧은 기존 비밀번호도 그대로 열리며, 열 때 바꾸기를 권합니다(**나중에**로 넘길 수 있음). 잠금 해제를 여러 번 틀리면 기다리는 시간(최대 5분)은 앱을 다시 켜도 이어집니다. → [처음 시작하기](guide/getting-started.md)
- **모델 계열 지정 위치**: 설정 → 이미지의 계열 표가 모델 화면으로 옮겨졌습니다. 설정에는 공유 모델 폴더 경로만 남습니다.
- **작품 설정의 등장인물 섹션 제목**을 뺐습니다. 이미지 프롬프트 변환이 더는 섹션을 읽지 않고, 검사의 "외모·의상 섹션 없음" 알림도 없어졌습니다.
- 샘플러·스케줄러는 이미지 생성 서버의 기본 목록에서만 고릅니다(확장 노드가 필요한 샘플러는 쓰지 않음).
- 화면에 영어로 보이던 서버 메시지 일부(프리셋 공유, LLM, 설치)를 한국어로 옮겼습니다.

### 데이터 옮기기

- **생성 프리셋과 화풍 조각 → 그림체 프리셋**: 처음 실행할 때 한 번 옮깁니다. 프리셋이 고르던 화풍은 그 프리셋의 artist 태그가 되고, 어느 프리셋도 쓰지 않던 화풍은 각각 그림체 프리셋이 됩니다(작품 화풍은 `<작품 ID>_<id>`). 예전 파일은 `styles.migrated.json`으로 남깁니다. 예전 생성 기록의 화풍 정보도 그대로 읽습니다.
- **캐릭터 이미지 설계의 원문 기록**: 새 변환부터 원문을 본문 조각으로 남깁니다. 예전에 변환한 설계는 그대로 읽어 상태를 보여 주고, 다시 변환하면 새 방식으로 바뀝니다.

### 설명서

- 새 페이지: [그림체 프리셋](guide/style-presets.md), [모델](guide/models.md).
- 프롬프트 라이브러리(구도·배경, 메모, 내보내기·가져오기), 캐릭터 이미지 설계(본문 전체·범위 지정 변환, 상태), 이미지 생성(업스케일·디테일러), 이미지 도구(생성 정보 표), LoRA(폴더 연결), 처음 시작하기·설정(비밀번호)을 고쳤습니다.

## 0.2.2

### 바뀐 점

- **이미지 메뉴**: 항목을 **준비**(프롬프트 라이브러리), **만들기**(완성도 보드, 생성, 생성 대기열, 생성·비교), **다듬기**(갤러리·검수, 이미지 도구), **학습**(LoRA) 묶음으로 나눠 보여 줍니다. 항목과 순서는 그대로입니다. → [이미지 생성](guide/generation.md)
- **이미지 도구**: 오른쪽 탭을 **프롬프트**(프롬프트 형식, 태깅), **이미지 손질**(후처리, 배경 제거, 인페인트), **파일**(WebP 변환, 검열) 묶음으로 나눴습니다. ComfyUI에서 실행하는 탭에는 **처리 방식**(이 PC(ComfyUI) / NovelAI)이 보입니다. 지금은 모든 도구가 이 PC에서만 되므로 NovelAI는 흐리게 보입니다. → [이미지 도구](guide/image-tools.md)
- **이미지가 많을 때 빠르게**: 이미지가 수만 장이어도 갤러리 목록, 판정 저장, 완성도 보드, 채택 내보내기가 느려지지 않습니다(5만 장 기준 판정 한 건 1.7초 → 0.1초, 여러 장 한꺼번에 판정 수십 초 이상 → 1초 안). 검수에 쓰는 이미지 해시를 `state/image/hashes.json`에 남겨 다시 시작해도 다시 계산하지 않습니다. 업데이트한 뒤 처음 **검수 상태**로 거를 때만 한 번 오래 걸릴 수 있습니다.
- **첫 화면을 빠르게**: 처음에 읽는 화면 코드를 줄였습니다(약 1.5MB → 0.6MB). 잠금 화면과 작품 목록이 먼저 뜨고, 작품 창·이미지 화면·설정·편집기는 처음 열 때 읽습니다(잠깐 "불러오는 중…"이 보일 수 있습니다).

### 설명서

- 이미지 메뉴와 이미지 도구 화면 캡처를 새 화면으로 바꾸고, 탭 묶음과 처리 방식을 설명했습니다.

## 0.2.1

### 고친 점

- **배포 대상에 올리기**: 갤러리에서 캐릭터·의상을 골라 열어도 작품 전체의 채택 이미지가 대상으로 잡히던 문제. 이제 미리보기·올리기·다시 올리기 모두 고른 범위만 씁니다. **올릴 등급**을 모두 끄면 전체 등급이 대상으로 잡히던 문제도 고쳐, 이제 올릴 것이 없다고 알리고 버튼을 끕니다. → [배포 대상에 올리기](guide/deployment.md)
- **프롬프트 라이브러리**
  - 목록을 다시 불러오거나 저장 응답이 늦게 오면 저장하지 않은 편집이 사라지던 문제. 다른 조각·종류로 옮기거나 **+**를 누를 때는 변경을 버릴지 묻습니다.
  - 작품 조각을 전역으로 바꿔 저장하면 작품과 전역에 둘 다 남던 문제. 이제 전역으로 옮겨집니다. 이미 쓰는 id로 새 항목을 만들 수 없습니다. → [프롬프트 라이브러리](guide/image-library.md)
- **태그 입력**: 줄바꿈으로 나눈 태그를 붙여 넣으면 한 태그로 붙고, 가중치 묶음 `(upper body, straight-on:1.4)`이 안의 쉼표에서 깨지던 문제. 붙여 넣기는 고른 글자 자리를 바꿉니다. 캐릭터 이미지 설계의 외모·의상 칸도 같습니다.
- **파일 가져오기**: 확장자가 대문자(`.MD`)인 파일이 저장 단계에서 거절되고 앞서 쓴 파일이 남아, 다시 하면 번호 붙은 복사본이 생기던 문제. 메타데이터가 깨진 JSX를 **본문째 메모로** 고르면 막히던 문제(이제 `.md` 메모로 들어옴). → [편집](guide/editing.md)
- **데이터셋·LoRA 학습**: 캐릭터가 많고 창이 낮으면 왼쪽 목록 글자가 겹치던 문제(갤러리 폴더 트리도 같음).
- **LLM 오류 안내**: 402 응답에 결제나 요금제가 필요하다는 안내를 붙이고, 작업 실패 알림·작업 패널·업로드 결과의 서버 메시지를 번역해 보여 줍니다.
- **설정 → 정보**: 문제·의견을 보내는 곳을 GitHub 이슈가 아니라 **도움말 → 오류 제보·기능 제안·질문·문의**로 안내합니다.

### 설명서

- 작품 목록과 작품 설정, 관계도·용어집·일관성 검사, 기록·비교·복원·휴지통, 설정 전체 페이지를 새로 만들고, 편집(빠른 열기·검색·검사 패널·이름 일괄 변경)과 AI 도구(뼈대 작성·드래프트)를 보강했습니다.

## 0.2.0

### 새 기능

WebP로 바꾸고 메타데이터를 지워 올리며, 같은 파일은 건너뛰고 같은 경로는 덮어씁니다. → [배포 대상에 올리기](guide/deployment.md)
- **배포 코드**: 표정(프롬프트 라이브러리)과 의상(캐릭터 이미지 설계)에 배포 경로에 쓰는 코드를 둡니다. 기본 표정은 `001`~`008`을 갖고 있고, 이미 쓰던 앱도 시작할 때 기본 표정에 채워 집니다. 같은 코드는 막지 않고 알려 줍니다.
- **파일 가져오기**: 파일 트리 우클릭 **가져오기…** 또는 탐색기에서 끌어 놓기로 `.md`·`.jsx` 파일을 작품에 들여옵니다. 메타데이터가 없는 Markdown 파일은 종류를 직접 골라야 들어오고(앱이 짐작하지 않음), 겹치는 ID·이름은 바꿔 제안합니다. 내보낸 폴더의 `_keywords.md`를 함께 고르면 키워드를 되살립니다. → [편집](guide/editing.md)

## 0.1.1

### 바뀐 점

- **작업 패널**: 상단 작업 버튼의 패널에 LLM 작업과 함께 이미지 대기열, 설치, LoRA 학습, 이미지 변환도 보이고, **열기**로 그 화면으로 갑니다. 버튼의 숫자도 이들을 셉니다.
- **작업 상태**: 모든 작업이 같은 상태(대기·실행 중·취소 중·완료·실패·취소됨·중단됨)를 씁니다. 취소하면 실제로 멈출 때까지 **취소 중**으로 보이고, 앱을 닫아 멈춘 LoRA 학습은 **중단됨**(다시 실행 가능)으로 남습니다.
- **저장하지 않은 변경**: 편집기, 설정, 프롬프트 라이브러리, LoRA 캡션 등 모든 편집 화면이 같은 방식으로 탭에 ● 표시를 하고, 탭을 닫거나 작품에서 나가거나 잠글 때 어느 탭인지 알려 줍니다. 저장하면 표시가 사라지고, 검색처럼 저장할 것이 없는 입력은 변경으로 세지 않습니다.
- **관계도·용어집**: 탭을 연 뒤 다른 창이나 채택한 초안이 먼저 바꿨다면, 탭의 옛 내용으로 덮어쓰지 않고 다시 불러온 뒤 알려 줍니다.
- **설명서**: [인터넷 이미지 서비스](guide/image-services.md)와 [프롬프트 라이브러리](guide/image-library.md) 페이지를 새로 만들었습니다. ComfyUI 없이 NovelAI·PixAI만으로 이미지를 만드는 경우와, 표정·구도·화풍·공통 프롬프트·공용 의상 부위·생성 프리셋 조각을 만들고 고치는 법을 안내합니다.

## 0.1.0

### 바뀐 점

- **인터넷 이미지 서비스**: ComfyUI 없이 **NovelAI**와 **PixAI**로도 캐릭터·의상·표정 조합을 생성합니다. 생성 화면 오른쪽 위 **생성 서비스**에서 고르고, 키는 **설정 → 이미지 → 인터넷 이미지 서비스**에 등록합니다(금고에 암호화). → [인터넷 이미지 서비스](guide/image-services.md)
  - NovelAI: V4.5·V5 등 모델 선택, 남은 Anlas와 Opus 무료 범위 표시.
  - PixAI: 모델(Haruka v2·Hoshino v2·Tsubaki.2), 마켓 주소로 등록한 LoRA 5개까지.
  - 한 번에 넣을 수 있는 장수 한도(기본 50장, 0이면 제한 없음), 요청 간격, 넣기 전 장수 확인, 같은 요청을 곧바로 다시 넣으면 확인.
  - 비용이 나갔을 수 있는 요청은 앱이 저절로 다시 보내지 않습니다. PixAI는 앱을 다시 켜거나 받기만 실패해도 같은 작업의 결과를 이어서 받습니다.
  - 이 PC의 LoRA·트리거 단어는 쓰이지 않고, 자동 검수에서 떨어져도 자동으로 다시 만들지 않습니다.
- **프롬프트 조각의 묶음과 사용 대상**: 라이브러리 조각마다 묶음(품질·배경 등)과 사용 대상(SDXL·IL, Anima, NovelAI, PixAI, 여러 개)을 정합니다. 생성 화면은 지금 서비스·모델 계열에 맞는 조각만 보여 주고, 맞지 않는 조각은 프롬프트에서 빼고 알려 줍니다.
- **툴팁**: 아이콘 버튼 등에 마우스를 올리거나 키보드로 초점을 옮기면 앱 툴팁이 바로 뜨고, 단축키도 함께 보입니다.

### 고친 점

- 큰 문서(수만 줄) 비교가 중단되던 문제.
- 기록 비교에서 복원한 뒤 파일 본문이 옛 내용으로 남던 문제.
- 테스트 세트 비교에서 같은 입력이 여러 번 있을 때 답변이 빠지던 문제, 시작 상황 파일이 없을 때 그냥 실행되던 문제.
- 대화 테스트·에이전트에서 세션이 끝났을 때 잠금 화면으로 가지 않던 문제.

- **에이전트 모드가 지침을 함께 읽음**: 모드마다 함께 읽을 지침을 정합니다(설정 → 지침의 모드 카드). JSX 만들기는 `jsx.md`, 모순·누락 찾기는 `consistency.md`, 로어북 정리는 `compression.md`를 함께 읽습니다. 에이전트 패널에 이번 요청에 들어가는 지침과 토큰이 보입니다. → [지침](guide/guidelines.md)
- **JSX 사용 규칙 개정**: 실행 환경(샌드박스·외부 통신 금지·스타일), 데이터 설계(배열·튜플로 토큰 줄이기), 응답 속 표기(컴포넌트 태그를 코드 블록으로 감싸지 않기)를 더했습니다.
- **갤러리에서 프리셋 저장**: 이미지 정보의 **이 설정으로 프리셋 저장**으로 모델·샘플러·화풍·공통 태그·LoRA를 프리셋으로 남깁니다. 캐릭터 전용 LoRA와 외모·의상·표정은 빠집니다.
- **내보내기 전 점검**: 없는 JSX 컴포넌트를 부르거나, 사용 안 함인 컴포넌트를 부르거나, 대화 상대가 없는 캐릭터면 오류로 알립니다. 내보내기 대화상자에 검사 결과와 오류 목록이 보이고, 오류가 남아 있으면 내보내기 전에 묻습니다.
- **설명서**: "지침" 페이지를 새로 썼고, 주소가 https://atelierx.cftm.net 으로 바뀌었습니다.

### 고친 점

- 이미지 자동 검수와 다른 LLM 요청이 겹치면 검수가 오류로 끝나던 문제(0.0.4에서 생김).
- 에이전트: 응답을 기다리는 동안 지운 파일이 제안을 채택하면 다시 생기던 문제. 응답 중 다른 대화로 옮기면 화면이 섞이던 문제(이제 응답 중에는 대화를 바꿀 수 없습니다).
- 편집기: 열어 둔 파일이 다른 곳에서 지워진 뒤 저장하면 파일이 다시 만들어지던 문제.
- 설정 탭: 저장한 뒤에도, 바로 저장되는 설정만 바꿔도 닫을 때 "저장하지 않은 변경"을 묻던 문제.
- 압축·이미지 프롬프트 작업이 외부 연결을 써도 하나씩만 돌던 문제(이 PC의 GPU를 쓰는 연결일 때만 하나씩).
- 작품에 플랫폼 프리셋 태그가 여럿일 때 지침을 앞쪽 태그의 프리셋에서 먼저 찾던 문제(이제 프리셋 값과 같이 뒤쪽 태그가 우선).

## 0.0.4

데이터를 지키는 쪽의 수정이 중심입니다.

### 바뀐 점

- **GPU를 함께 쓰는 LLM 연결**: LLM 연결마다 **이 PC의 GPU 사용**을 둡니다. 주소가 이 PC(127.0.0.1·localhost)면 기본으로 켜집니다. 켜진 연결의 요청(압축·대화 테스트·에이전트 포함)은 진행 중인 이미지가 끝난 뒤 시작하고, 응답이 끝날 때까지 새 이미지·검수·학습은 기다립니다. 기다리는 동안 "GPU를 기다리는 중"이 보입니다. 외부 연결은 설정의 동시 요청 수만큼만 함께 보냅니다. → [LLM 연결](guide/connections.md)
- **내보내기 폴더 확인**: 작품 폴더 안이나 그 상위 폴더, 다른 작품, 앱 폴더 안으로는 내보내지 않습니다. 대화상자에 이유를 보여 주고 버튼을 막습니다.

### 고친 점

- 에이전트: 응답을 기다리는 동안 파일을 저장하면, 옛 내용으로 만든 제안이 그 변경을 덮어쓸 수 있던 문제. 이제 요청을 보낸 뒤 바뀐 파일의 제안은 채택할 수 없다고 알려 줍니다. 에이전트에게 보내지 않은 파일을 고치는 제안에는 경고를 붙입니다.
- 대화 테스트: **입력 다시 보내기** 중 멈춤을 누르거나 오류가 나거나 화면을 떠나도 나머지 입력을 계속 보내던 문제.
- 기록: 스냅숏 뒤에 만든 파일을 하나만 되돌리면 아무 일도 없이 "되돌렸습니다"가 나오던 문제. 이제 그 파일은 휴지통으로 가고, 바뀐 것이 없으면 그렇게 알려 줍니다.
- 편집기: 저장 충돌 뒤 **다시 불러오기**를 눌러도 화면에 옛 내용이 남던 문제. 저장하지 않은 변경이 있으면 먼저 묻습니다.
- 페르소나 목록: 창을 연 뒤 다른 창에서 목록이 바뀌면 저장이 충돌 없이 덮어쓰던 문제.
- 설정: 왼쪽 목록에서 다른 항목으로 갔다 오면 저장하지 않은 입력이 사라지던 문제.

## 0.0.3

### 새 기능

- **에이전트 패널**: 오른쪽 보조 패널의 **에이전트** 탭에서 모드(아이디어 정리, 시작 상황 쓰기, 캐릭터 다듬기, 로어북 정리, JSX 만들기, 모순·누락 찾기, 자유 대화)를 골라 LLM과 대화합니다. 에이전트는 파일 전체를 제안하고, 검토 탭에서 바뀐 부분만 골라 채택합니다. 편집기에서 `Ctrl+L`로 고른 줄을 첨부합니다. → [에이전트 패널](guide/agent.md)
- **설정 → 지침**: 에이전트 모드와 압축·모순 검사·이미지 프롬프트 등 작업 지침을 묶음별로 접어 보고 고칩니다. 기본값과 비교·되돌리기, 새 모드 추가를 할 수 있습니다.
- **페르소나 목록**: 테스트 화면의 **페르소나** 버튼으로 이름과 여러 줄 설명을 가진 페르소나를 저장하고 골라 씁니다. 목록은 모든 작품이 함께 씁니다. → [대화 테스트](guide/chat-test.md)
- **도움말 메뉴**: 사용 설명서(웹·이 PC), 단축키, 업데이트 확인, 릴리스 목록, AtelierX 정보, 웹 브라우저에서 열기. 설정 → 일반에서 "시작할 때 업데이트 확인"을 켤 수 있습니다.
- **앱 아이콘**: 창, 화면 머리, 실행 파일에 새 아이콘을 씁니다.

### 고친 점

- JSX 예시 자동 저장: 저장 응답이 늦게 도착하면 최신 입력이 옛 내용으로 돌아가던 문제, ID가 정해지기 전에 연 미리보기가 잘못된 위치에 저장하던 문제, 탭을 빨리 바꾸면 "저장 안 됨"이 남던 문제.
- 테스트 화면의 페르소나 설명이 이름 없이 입력되면 빠지던 문제. 서버 오류가 영어로 보이던 문제.
- 오프라인 설명서의 페이지 순서와 버전 표시.
- 테스트 화면: 응답 속 컴포넌트 호출이 코드 블록 안에 있거나 읽을 수 없는 형식(`data={...}` 등)이라 그려지지 않을 때, 응답 아래와 오른쪽 JSX 목록에 그 이유를 알려 줍니다.
- 에이전트: 예약 참조 {{user}}·{{char}}를 백틱으로 감싸 쓰던 문제(지시문 수정, 감싼 제안에 경고). 제안 카드에 채택·버림 상태 표시.
- 생성 대기열의 후처리 항목에 작업과 파일 이름을 표시합니다. 생성·이미지 도구 화면의 선택이 "저장하지 않은 변경"으로 잡히던 문제, 생성 화면에서 이름이 세로로 꺾이던 문제.
- 샘플 simulation 메인 프롬프트의 "요소를 읽을 수 없습니다" 경고.

### 알려진 점

- 업데이트 후 탐색기가 실행 파일의 예전 아이콘을 보여 줄 수 있습니다. Windows 아이콘 캐시 때문이며 앱 동작과는 관계없습니다.
