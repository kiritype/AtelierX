# 사용 목적별 시작 안내

AtelierX에서 하려는 작업을 먼저 고르세요. 원고 편집만 한다면 이미지 서비스를 준비할 필요가 없고, 직접 입력으로 이미지를 만든다면 LLM 연결을 건너뛸 수 있습니다.

처음 실행한다면 [첫 실행](first-run.md)에서 잠금 비밀번호를 정하고 [샘플 작품](create-work.md)을 열어 둡니다. 실제 작품을 바꾸기 전에 샘플로 버튼 위치와 저장 결과를 확인할 수 있습니다.

## 원고를 쓰고 대화로 확인하기

**준비:** 작품 하나. AI와 대화하려면 사용할 LLM 연결이 필요합니다.

1. [작품 만들기](create-work.md)에서 샘플 파일을 열고 짧게 편집합니다. 저장 표시를 확인합니다.
2. [LLM 연결](connect-llm.md)에서 모델 목록과 응답을 확인합니다. LLM 없이 직접 쓸 때는 3~4번의 AI 작업과 5번의 대화 테스트도 건너뛰고, 원고를 편집한 뒤 [Markdown 내보내기](test-and-export.md)로 바로 진행하세요.
3. [에이전트로 원고 쓰기](write-with-agent.md)에서 작업 범위를 정하고 제안을 받습니다. 검토한 변경만 채택합니다.
4. [LLM으로 다듬기](refine-with-llm.md)에서 필요한 도구를 선택합니다. 모든 도구를 사용할 필요는 없습니다.
5. [테스트와 내보내기](test-and-export.md)에서 시작 상황으로 대화한 뒤 내보낸 파일을 확인합니다.

**완료 확인:** 제안이 실제 원고에 반영되었고, 내보낸 파일에 필요한 내용이 들어 있습니다. 제안을 받기만 한 상태와 채택해 저장한 상태는 다릅니다.

## 자유 프롬프트로 이미지 한 장 만들기

**준비:** 작품 하나와 이미지 서비스 하나. 캐릭터 이미지 설계나 LLM 연결은 필수가 아닙니다.

1. [이미지 환경 준비](../guide/image-setup.md)에서 ComfyUI 또는 인터넷 서비스를 고릅니다.
2. [단일 이미지 생성](../guide/single-generation.md)에서 서비스·모델과 장면을 정합니다.
3. 조합된 프롬프트와 생성 설정을 확인하고 **1장 생성**을 누릅니다.
4. 결과의 **기록된 설정**에서 실제 사용된 값을 확인합니다. 더 오래된 결과는 [갤러리](../guide/gallery-export.md)에서 찾습니다.

**완료 확인:** 결과 이미지와 기록이 함께 남습니다. 입력을 바꾼 뒤에도 이전 이미지의 기록은 그대로이며, 설정 불러오기와 재생성은 별도 동작입니다.

## 그림체를 비교하고 다른 장면에 쓰기

**준비:** 연결한 이미지 서비스와 사용할 모델. 이미 쓰던 그림체가 있다면 기준 프리셋으로 선택합니다. [이미지 환경 준비](../guide/image-setup.md)

1. 작품 목록 또는 작품 창의 **도구 → 그림체 탐색**을 엽니다.
2. [그림체 탐색](../guide/style-explorer.md)에서 기준 프리셋과 추가 작가·LoRA 후보, 개수·가중치 범위를 정합니다.
3. 장수와 상한을 확인한 뒤 생성하고, A/B 비교에서 마음에 드는 결과를 고릅니다.
4. 순위에서 새 프리셋으로 저장합니다.
5. 작품을 열고 [그림체 프리셋](../guide/style-presets.md)에서 **단일 이미지 생성에 적용**합니다. 다른 장면을 입력하고 설정을 확인한 뒤 생성합니다.

**완료 확인:** 저장한 그림체의 설정은 적용되고 직접 입력한 장면은 유지됩니다. 탐색을 열거나 프리셋을 적용하는 것만으로 이미지를 만들지는 않습니다.

## 캐릭터의 의상·표정별 이미지 만들기

**준비:** 캐릭터 파일과 저장된 이미지 설계, 이미지 서비스 하나. 본문에서 이미지 태그를 자동 변환할 때는 LLM도 필요합니다.

1. [캐릭터 이미지 만들기](character-images.md)에서 외모·의상을 설계합니다. LLM 없이 만들려면 **이미지 프롬프트** 탭에서 직접 입력해 저장합니다. [캐릭터 이미지 설계](../guide/character-images.md)
2. [일괄 생성](../guide/batch-generation.md)에서 캐릭터·의상·표정을 고르고 최종 조합 수와 프롬프트를 확인합니다.
3. 생성 완료 후 [갤러리](../guide/gallery-export.md)에서 이미지를 검토하고 필요한 조합의 이미지를 채택합니다.
4. 완성도 보드에서 빠진 조합을 확인하고 채택 이미지를 ZIP으로 내보냅니다.

**완료 확인:** 생성 완료 장수뿐 아니라 필요한 조합의 **채택 상태**도 확인합니다. 통과로 채택한 이미지는 조합마다 하나입니다.
