# ADR-0014: 검사 상세·Validation Profile

2026-09-13 [ADR-0023](0023-negative-prompt-sources.md)으로 Negative 검사 범위를 부분 변경했다. 전역 Negative는 검사에서 제외하고 캐릭터 Negative만 금지 요소로 검사한다. 아래 이전 설명보다 우선하며 Accepted 상태는 유지한다.

- 상태: Accepted
- 작성일 / 확정일: 2026-09-13
- Supersedes / Superseded by: 없음
- 관련: [ADR-0004](0004-validation-outcomes-and-errors.md), [ADR-0008](0008-group-reference-selection.md), [ADR-0011](0011-validation-input-context.md), [ADR-0012](0012-validation-image-transfer-and-required-input.md)

## 결정

Profile은 수행할 검사와 기준을 저장한 설정이다. 단일·묶음 Profile을 분리하고 기본 Profile을 제공하며 사용자가 복제·수정할 수 있다. 초기에는 Profile 상속을 제공하지 않는다. Core가 설정을 관리하고 검증 요청 시 고정하며, 이후 변경은 새 요청부터 적용한다.

| 검사 | 기준 | 기본 |
| --- | --- | --- |
| 필수 사전 검사 | 파일 접근·형식·Decode·입력 유효성. 실패는 오류 | 항상 실행, 비활성화 불가 |
| 출력 조건 | 요청한 최종 해상도·비율·포맷·Alpha 조건 비교. 활성 검사에서 다르면 불합격 | On |
| Positive Prompt | 명시 요소 누락·불일치는 불합격. ADR-0004 유지 | On |
| Negative Prompt | 관찰 가능한 금지 요소 검사. low quality 등 추상 표현만으로 불합격시키지 않음 | On |
| 신체 이상 | 보이는 손·얼굴·사지 구조 이상. 부위별 On/Off 지원, 가려진 부위를 추측하지 않음 | Off |
| Metadata | 별도 선택 검사. 누락만으로 외형 불합격 처리하지 않음 | Off |
| 묶음 일관성 | ADR-0007~0009의 기준·비교 불충분·판정 규칙 유지 | On |

신체 이상 검사와 Prompt 일치 검사를 구분한다. Prompt에 명시된 부위·동작이 보이지 않는 문제는 기존 Prompt 기준으로 판단하며, 신체 이상 검사 Off가 그 기준을 해제하는 것은 아니다.

## 검사 순서와 결과

1. 필수 사전 입력 검사.
2. 활성 출력 조건 검사.
3. 활성 AI 검사.

입력 오류 또는 출력 조건 불합격이 확인되면 이후 AI 검사를 생략하고 이유를 표시한다. 활성 검사 중 하나라도 불합격이면 종합 불합격이며 오류·미완료를 합격으로 취급하지 않는다. 여러 판정과 실행 오류가 함께 발생한 경우의 응답 우선순위는 단일·묶음의 기존 오류 경계를 유지하고 구체 Schema에서 정의한다. 단일 실행 오류를 부분 불합격 결과로 자동 재생성하는 결정이 아니다.

초기에는 판정·근거를 중심으로 사용한다. AI가 제공한 Score·Confidence 숫자만으로 합격 여부를 결정하지 않는다. 묶음의 비교 불충분을 불합격이나 실행 오류와 동일시하지 않는다.

## 사용자 제어와 확장 검토

사용자는 이후 검사 설정을 제어할 수 있도록 고려해 달라고 요청했다. 이미 확정한 Profile 복제·수정과 검사별/부위별 On/Off를 기반으로, 검사 기준·기본값 등 세부 제어 확장을 후속 검토한다. 구체 조절 항목·범위·UI·권한과 기본 Profile 편집/복원 방식은 아직 확정하지 않는다.

필수 입력 검사는 비활성화할 수 없다. 검사를 끄거나 일부가 실행되지 않았을 때 검사 범위를 결과에서 식별할 수 있어야 하며, 수행하지 않은 검사를 통과로 표시하지 않는 ADR-0012 원칙을 유지한다. 검사 설정 제어 요청을 임의의 모든 검사·오류 처리를 무력화할 권한으로 확대하지 않는다.

## 남은 결정

Profile 필드·식별·버전·저장 API, 구체 Negative Prompt 요소 추출, 신체 이상 판정 기준, Metadata 검사의 영향, Alpha 조건의 세부 의미, 검사 설정 사용자 제어의 상세 범위, Provider별 구현·불확실성 표현·응답 Schema는 후속 결정이다.

## 충돌 및 대체 확인

ADR-0001~0013과 대조했다. Core 설정 소유·요청 입력 고정·Prompt 판정·오류 후 자동 실행 금지·묶음 비교 부족 및 중복 제외를 유지한다. 검사 후보와 Profile 운영을 구체화하며 기존 Accepted 결정을 대체하지 않는다. ADR-0005는 Proposed를 유지한다.
