# ADR-0008: 묶음 검증 기준 선정과 비교 부족 처리

- 상태: Accepted
- 작성일 / 확정일: 2026-09-13
- Supersedes / Superseded by: 없음
- 관련: [ADR-0007](0007-group-image-validation.md), [ADR-0004](0004-validation-outcomes-and-errors.md)

## 배경

묶음 이미지의 자세·구도·표정은 서로 다르므로 한 이미지가 모든 비교 특징을 보여 주지는 않는다. 기준 선정과 비교 자료 부족을 구분하고, 비교하지 못한 결과를 합격으로 표시하지 않아야 한다. 아래는 사용자가 확정한 현재 기준이며 이후 검토를 통해 변경할 수 있다.

## 결정

| 항목 | 현재 확정 기준 |
| --- | --- |
| 선정 후보 | 해당 작품·캐릭터·의상 그룹의 단일 검증 통과 이미지 |
| 선정 우선순위 | 얼굴·머리·의상 등 비교 특징이 잘 보이고 가림·과도한 원근이 적은 이미지 우선 |
| 기준 구성 | 대표 기준 1장. 대표에서 보이지 않는 특징은 보조 이미지로 비교 |
| 사용자 수정 | 대표 기준을 변경할 수 있으며 ADR-0007의 기준 교체·재검증 확인 흐름 적용 |
| 후보 없음 | 기준을 선정하지 않고 묶음 검증 대기. 단일 검증 통과 이미지가 필요함을 안내 |
| 그룹 이미지 1장 | 단일 결과는 유지하고 묶음 일관성 검사는 비교 대상 부족으로 미실행 |
| 일부 특징 비교 불가 | 보이는 특징만 판정하고 나머지는 비교 불가 항목으로 명시. 전체 일관성 합격으로 표시하지 않음 |
| 보조 선정 | 단일 검증 통과 이미지 중 필요한 특징이 보이는 이미지를 시스템이 선택. 사용자 확인·수정 가능 |
| 대표·보조 충돌 | 다수결로 정답을 결정하지 않고 사용자에게 기준 확인 요청 |
| 새 이미지 추가 | 기존 기준을 유지하고 새 이미지만 단일 검증 후 일관성 검사. 기준 자동 교체 없음 |
| 기준 이미지 삭제 | 새 기준 선정·사용자 확인 후 ADR-0007의 기준 교체 절차 적용. 사용자에게 알리지 않고 교체하지 않음 |

비교 대상 부족·비교 불가는 묶음 검증에 필요한 상태 의미다. ADR-0005의 `passed/rejected/error`에 임의로 매핑하거나 새로운 enum을 여기서 확정하지 않는다. 구체 결과 구조는 묶음 응답 계약에서 정한다.

단일 검증의 Prompt 명시 요소가 보이지 않으면 불합격이라는 ADR-0004 기준은 유지한다. 단일 Prompt 충족 여부와 그룹 이미지 사이에서 비교할 자료가 충분한지는 별개다.

## 대안과 영향

대표 1장만으로 모든 특징을 판단하는 대신 보조 자료를 사용한다. 대표를 여러 장 동등하게 두기보다 대표 1장을 명확히 하고 비교 부족·충돌을 사용자에게 보여 준다. 자동 선정 결과가 캐릭터의 정답임을 보장하지 않으며, 충돌은 다수결로 해소하지 않는다.

## 변경 관리와 이력

사용자는 이후 선정 기준이 변경될 수 있음을 명시했다. 이번 합의는 미확정 제안이 아니라 **현재 적용할 확정 기준**이다. 변경 시 사용자와 논의하고 ADR 절차에 따라 변경 날짜·이유·이전/새 기준·영향 범위를 기록한다. 기존 결정을 대체하면 supersede 관계와 유지되는 범위를 명시하며 과거 결정을 지우지 않는다.

기준 변경이 기존 판정의 유효성과 재검증에 미치는 영향도 변경 검토에 포함한다. 선정 알고리즘·결과 저장의 구체 버전 필드는 이번에 확정하지 않는다.

| 날짜 | 이력 |
| --- | --- |
| 2026-09-13 | 사용자 승인으로 최초 확정. 대표 1장+보조 자료, 비교 부족/충돌 처리, 추가·기준 삭제 처리 채택. 이후 변경 가능성과 기록 보존 요청 반영 |

## 미결정 사항

선정 점수·가중치·동점 처리·보조 이미지 수, 구체 AI/알고리즘, 이미지 1장 조건의 API 표현, 부분 비교 결과의 집계·응답 Schema, 보조 교체/삭제 시 영향 범위, 그룹 완료·부분 실패·동시성은 후속 결정이다.

[ADR-0009](0009-group-validation-results.md)에서 이미지별 결과·그룹 요약·기준 유효성·부분 오류 보존·확인 중 기준 변경 처리를 확정했다. 위 결과/집계 미정 범위는 필드명·기계 검증 Schema 등 상세 계약으로 한정한다.

[ADR-0010](0010-group-completion-and-partial-failure.md)에서 고정 생성 대상·묶음 시작 조건·부분 실패/취소 처리를 확정했다. 생성 현황과 일관성 요약을 분리하며 전체 일치는 실제 비교 대상에 한정한다. 위 그룹 완료·부분 실패 미정 표현은 구체 상태/접수/동시성 계약으로 한정한다.

## 충돌 및 대체 확인

ADR-0001~0007의 책임·판정·오류·재생성 정책을 유지한다. ADR-0007에서 열어 둔 선정·부족·이미지 추가·기준 삭제 정책을 구체화하며 기존 결정을 대체하지 않는다. ADR-0007은 Accepted, ADR-0005는 Proposed로 유지한다.
