# ADR-0009: 묶음 검증 결과와 그룹 요약·사용자 확인

- 상태: Accepted
- 작성일 / 확정일: 2026-09-13
- Supersedes / Superseded by: 없음
- 관련: [ADR-0007](0007-group-image-validation.md), [ADR-0008](0008-group-reference-selection.md), [ADR-0005 초안](0005-validation-response-contract.md)

## 결정 범위

묶음 검증 결과가 제공할 정보와 그룹 요약 방식, 사용자 선택·확인 동작을 확정한다. 필드명·enum 문자열·HTTP 매핑·전체 기계 검증 Schema는 이번에 확정하지 않는다.

## 이미지별 결과와 비교 기준

| 항목 | 결정 |
| --- | --- |
| 검증 대상 연결 | 작품·캐릭터·의상 그룹과 이번 검증 대상 이미지 목록을 연결 |
| 비교 기준 기록 | 실제 사용한 대표·보조 이미지와 당시 기준을 기록해 기준 변경 후에도 과거 결과 해석 가능 |
| 이미지별 판정 | 일치 / 불일치 / 비교 불충분 / 실행 오류 구분 |
| 판정 근거 | 비교 특징·기대 외형·관찰한 차이·비교 불가 항목과 사유 제공 |
| 결과 유효성 | 현재 기준의 결과인지, 기준 변경으로 재검증이 필요한 과거 결과인지 표시 |
| 일부 실행 오류 | 정상 완료된 다른 이미지 결과를 보존하고 오류 대상을 구분해 재검증 가능 |

비교 불충분은 이미지 불일치나 Provider 실행 오류와 다르다. 미검증 대상은 완료 판정으로 꾸미지 않고 그룹 집계에서 별도로 구분한다. 기준 변경 이전 결과는 이력으로 보존하되 현재 기준에 대한 완료 판정으로 집계하지 않는다.

## 그룹 요약 방식

그룹 요약은 이미지별 결과의 집계다. 별도의 AI 다수결이나 평균 점수로 이미지별 불일치를 덮지 않는다. 판정별 이미지 수·재검토 대상 목록과 이번 검증의 대상 범위를 제공한다. 일부 이미지 재검증 결과를 그룹 전체 재검증 결과처럼 표시하지 않는다.

| 요약 | 조건 |
| --- | --- |
| 전체 일치 | 현재 기준으로 모든 대상의 비교가 완료됐고 모두 일치 |
| 불일치 있음 | 하나 이상 불일치가 확인됨. 비교 불충분·오류·미검증이 함께 있으면 별도로 표시 |
| 판정 미완료 | 확인된 불일치는 없지만 미검증·비교 불충분·오류가 남아 있음 |

예: 검증 대상 10장 중 일치 7·불일치 1·비교 불충분 1·실행 오류 1이면 **불일치 있음**이며 불일치 1장과 나머지 확인 필요 2장을 구분해 안내한다. 10장 중 일치 9·실행 오류 1이면 **판정 미완료**다. 다수 이미지가 일치해도 전체 일치로 표시하지 않는다.

ADR-0008의 후보 없음·그룹 이미지 1장으로 검사 미실행 상태와 사유도 유지하며, 빈 집계나 미실행을 전체 일치로 표시하지 않는다. 그룹 대상의 구체 ID 집합·대표/보조 자료와 집계 대상의 표현은 후속 Schema에서 명시한다.

## 사용자 선택과 확인

- 재검증: 문제가 있는 이미지 중 사용자가 대상을 선택하며 기존 이미지와 현재 기준으로 다시 검사한다.
- 재생성: 불일치 이미지·사유를 보여주고 사용자가 대상을 선택·확인한다. 비교 불충분·실행 오류만으로 재생성을 권하지 않는다. 기존 수동 재생성 가능성을 금지하는 것은 아니다.
- 확인 중 기준 변경: 화면 확인 이후 기준이 바뀌면 이전 기준으로 실행하지 않고 변경 내용을 보여준 뒤 다시 확인한다. Core가 현재 기준과 요청의 기준 연결을 확인하며 Client는 안내·사용자 선택을 전달한다. 구체 동시성 계약은 후속 정의한다.
- ADR-0007의 기준 교체 후 그룹 재검증 확인과 결과 확인 후 선택 재생성 확인을 유지한다. 이 결정으로 자동 묶음 재생성·자동 검증 재시도를 도입하지 않는다.

## 영향과 남은 결정

부분 성공을 보존하면서 불일치와 미완료를 함께 보여 줄 수 있다. 이미지별 상세, 그룹 집계, 검증 범위, 기준 유효성이 서로 모순되지 않도록 계약이 필요하다.

필드명·enum·Endpoint·HTTP·페이지 조회, 판정별 에러코드, 기준/검증 식별·버전 저장, 집계 대상과 참조 자료의 구체 표현, 변경 확인의 원자성·실행 중 기준 변경·그룹 추가/삭제 경쟁은 미정이다. 선정 기준은 ADR-0008의 변경 기록 원칙을 유지한다.

[ADR-0010](0010-group-completion-and-partial-failure.md)에서 고정 생성 대상·묶음 시작 조건·부분 실패/취소 처리를 확정했다. 생성 현황과 일관성 요약을 분리하며 전체 일치는 실제 비교 대상에 한정한다. 위 그룹 완료·부분 실패 미정 표현은 구체 상태/접수/동시성 계약으로 한정한다.

## 충돌 및 대체 확인

ADR-0001~0008과 책임·판정·재생성 경계를 대조했다. ADR-0007·0008의 미정 결과 구조를 의미 수준에서 구체화하며 기존 Accepted 결정을 대체하지 않는다. ADR-0005는 단일 이미지 응답 초안으로 Proposed 상태를 유지한다. 단일 이미지 오류 응답의 result=null 원칙을 그룹의 다른 이미지 정상 결과까지 폐기하는 규칙으로 확대하지 않는다.
