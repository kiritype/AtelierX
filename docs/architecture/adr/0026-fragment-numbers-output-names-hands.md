## 결정할 질문

이미지를 `작품\캐릭터\복장\조각번호` 형태의 파일명으로 저장하기 위한 조각 번호 규칙, 파일명 충돌 처리, 의상의 손 항목, Discord 결과 저장 위치를 정한다.

## 결정 (2026-09-23 사용자 확정)

- **조각 번호:** 이미지별 조각의 번호는 사용자가 입력·수정한다. 파일명에 쓸 수 없는 문자(`<>:"/\|?*`, 제어 문자, 끝의 점·공백, Windows 예약 이름)만 막고 숫자·문자를 모두 허용한다. 공통 적용 조각은 번호가 없다.
- **중복 번호:** 같은 번호가 있으면 Backend가 경고를 반환하고 Frontend가 확인 창을 띄운다. 사용자가 확인하면 저장을 허용한다.
- **출력 파일명:** 생성 결과는 ComfyUI 출력 폴더 아래 `AtelierX\<작품>\<캐릭터>\<복장>\<조각번호>.png`(WebP를 만들면 같은 이름의 `.webp`)로 저장한다. 같은 이름이 이미 있으면 `<조각번호> (2)`, `(3)`…을 붙이며 PNG·WebP는 같은 번호를 쓴다. 이름 요소의 금지 문자는 치환한다. Core가 경로를 정하고 Generation·Encode Node가 실제 파일을 쓴다.
- **손 항목:** 의상에 상의·하의·액세서리와 같은 수준의 "손" 항목을 추가한다. 이미지별 조각에 "손 포함" 체크를 두어 생성 시 포함 여부를 정한다(기본 포함). 손 항목은 포함됐을 때만 생성·검사 Prompt에 들어간다.
- **Discord 결과:** Discord 봇 생성 결과는 `AtelierX\discord\<날짜>\` 아래 별도 폴더에 저장한다.

## 영향과 트레이드오프

- 번호가 바뀌어도 이미 저장된 파일 이름은 바꾸지 않는다. 이미지 기록에는 생성 당시 번호가 남는다.
- 같은 조각을 다시 생성하거나 재생성하면 `(2)` 등 번호가 붙은 파일이 쌓인다.
- AtelierX 내부 이미지 저장소(Generation 데이터 폴더)와 API 조회 방식은 그대로다. 사람이 보는 ComfyUI 출력 폴더 구조가 바뀐다.
- 기존 자동 번호 순서 기록은 더 쓰지 않는다. 기존 조각은 현재 번호를 문자열로 유지한다.
