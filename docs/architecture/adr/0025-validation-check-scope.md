# ADR-0025: 단일 검증의 검사 대상 범위와 판단 불가 항목

- Supersedes: 없음 (ADR-0004의 "Prompt 전체 기준 불합격"과 현행 평가 규칙 일부를 변경)
- Superseded by: 없음
- 관련 요구사항 / ADR: [ADR-0004](0004-validation-outcomes-and-errors.md), [ADR-0017](0017-regeneration-change-validation.md), [ADR-0022](0022-prompt-composition.md), [ADR-0023](0023-negative-prompt-sources.md), [Validation 현행 사양](../../modules/validation.md)

## 결정할 질문

단일 검증이 생성 Prompt의 어떤 부분을 "이미지에 보여야 하는 요소"로 검사하고, 이미지로 판단할 수 없는 요소를 어떻게 다룰지 정한다.

## 배경과 제약

2026-09-23 실사용 기록 진단: 실사용 이후 단일 검증 통과 0건(불합격 26, 오류 7).

- 전역 품질 프롬프트(`year_2025`, `absurdres`, `score_9` 등)와 공통 적용 조각의 화가 태그가 매번 "이미지에 없음"으로 판정돼 모든 이미지가 불합격했다.
- 문장형 외형 설명이 쉼표로 잘려 나이·키 같은 판단 불가 속성이 섞인 조각이 검사됐고, 구도상 보이지 않는 요소(상반신 구도의 키 등)도 불합격으로 셌다.
- VLM의 재생성 변경 제안이 형식에 맞지 않으면 판정 전체가 오류(`VAL_REGENERATION_PROPOSAL_INVALID`)로 끝났다.

## 결정 (2026-09-23 사용자 확정: A·B·C·D 모두 적용)

- **A. 출처 기반 검사 범위:** Core는 검사 요청에 검사할 Positive 항목을 출처와 함께 따로 보낸다. 전역 품질 프롬프트와 공통 적용 조각(스타일·품질·화가)은 검사하지 않는다. 캐릭터 외형(또는 C의 핵심 특징), 의상(상의·하의·액세서리·손 중 포함된 것), 이미지별 조각만 검사한다. 생성에 쓰는 전체 Prompt는 바뀌지 않는다.
- **B. 판단 불가 항목:** 항목 상태에 `not_assessable`을 추가한다. 이미지로 판단할 수 없는 속성(나이·성격·키 등)이나 요청한 구도 때문에 화면에 나올 수 없는 요소는 `not_assessable`로 판정하고 불합격으로 세지 않으며 결과에 따로 표시한다. 한 항목 안에서는 볼 수 있는 속성만 판단한다. 문장형 텍스트는 쉼표가 아니라 문장 단위로 나눈다.
- **C. 캐릭터 검사용 핵심 특징:** 캐릭터에 짧은 확인 항목 목록(예: 머리색, 오드아이, 아호게)을 둔다. 값이 있으면 외형 검사는 문장형 외형 설명 대신 이 목록으로 한다. 비어 있으면 외형 설명을 B 규칙으로 검사한다.
- **D. 재생성 제안 오류 분리:** 재생성 변경 제안만 형식이 잘못된 경우 제안을 버리고 판정(불합격)은 유지한다. 버린 사실은 진단 정보로 남긴다.

## 영향과 트레이드오프

- 평가 버전을 올린다. 과거 결과는 재작성하지 않는다.
- `not_assessable`을 모델이 과하게 쓰면 누락을 놓칠 수 있다. 항목별 결과에 표시해 사람이 볼 수 있게 한다.
- 스타일·품질 준수는 단일 검증 대상에서 빠진다(묶음 일관성 검사와는 별개).

## 충돌 및 대체 확인

- ADR-0004: "Prompt 기준 불합격" 원칙은 유지하되 기준 Prompt의 범위를 A로 한정하고 `not_assessable`은 불합격이 아니다(부분 변경).
- ADR-0017: 재생성 변경값 검사 규칙은 유지하고, 제안 형식 오류의 처리만 D로 바꾼다(부분 변경).
- 현행 사양의 "품질/스타일 표현도 생략하지 않음", "구도 요구가 화면 밖 누락을 면제하지 않음" 규칙은 이 ADR로 대체된다.
