# ADR-0007: 단일 이미지와 묶음 이미지 검증

- 상태: Accepted
- 작성일: 2026-09-13
- 확정일: 2026-09-13
- Supersedes / Superseded by: 없음
- 관련: [ADR-0003](0003-generation-execution-and-queue.md), [ADR-0004](0004-validation-outcomes-and-errors.md), [ADR-0006](0006-validation-manual-retry.md)

## 배경

작품·캐릭터·의상 그룹에는 자세·구도·표정 등에 따라 서로 다른 Prompt로 생성된 여러 이미지가 속한다. 단일 이미지의 Prompt 일치와 그룹 내 캐릭터 일관성을 구분할 필요가 있다.

## 결정 — 2026-09-13 사용자 합의

- 묶음 검증의 비교 대상은 단일 이미지 검증을 통과한 이미지다.
- 일관성은 그룹에서 유지해야 하는 캐릭터 외형·의상을 기준으로 비교한다. 자세·구도·표정은 캐릭터 표현을 구성하는 주요 요소지만 이미지별 차이를 허용하며, 서로 다르다는 이유만으로 일관성 불합격으로 처리하지 않는다. 각 이미지의 해당 요소가 생성 Prompt와 일치하는지는 단일 검증의 범위다.

## 단일·묶음 검증의 실행과 책임

단일 검증은 생성 이미지별로 수행한다. 묶음 검증은 작품·캐릭터·의상 그룹의 생성·단일 검증 처리가 끝난 뒤 단일 검증 통과 이미지의 일관성을 검사한다. Core가 그룹 상태·검증 요청·이력을 관리하고 Validation이 전달받은 대상과 기준 이미지를 검사한다. 그룹 완료 및 부분 실패의 구체 상태 계약은 후속 정의한다.

## 중복 검사 제외

초기 범위에서 중복 검사와 중복에 따른 불합격·자동 제외·파일 삭제는 제공하지 않는다. 서로 다른 Prompt가 서로 다른 출력을 보장하지는 않지만, 같은 캐릭터의 유사한 이미지는 정상 변형일 수 있다. 요청한 자세·표정 등이 반영되지 않은 문제는 단일 Prompt 일치 검사에서 다룬다. 기존 중복 관계·제외 후보 반환안은 미채택 권고로 보존한다.

## 선택 이미지 재검증

- 묶음 검증 후 문제가 있는 이미지만 선택해서 재검증할 수 있다.
- 선택 대상과 그룹 기준 이미지를 함께 전달한다. 판정을 갱신할 대상과 비교 자료를 구분한다.
- 선택 대상의 판정만 갱신하고 나머지 판정과 기존 검증 이력은 보존한다. 단, 기준 교체 시에는 아래 유효성 규칙을 적용한다.
- 기존 이미지의 재검증과 이미지 재생성은 별도 동작이다. 대체 이미지를 생성하면 단일 검증을 통과시킨 뒤 그룹 기준과 일관성을 검사한다.
- 묶음 불합격을 이유로 자동 이미지 재생성을 도입하지 않는다.

## 기준 이미지 선정·교체와 사용자 확인

1. 시스템은 단일 검증을 통과한 그룹 이미지에서 기준 이미지를 선정한다. 사용자는 다른 이미지로 수정할 수 있다. 자동 선정 알고리즘은 후속 설계한다.
2. 기준이 교체되면 기존 판정은 이전 기준에 대한 이력으로 보존하고 새 기준에 대한 그룹 재검증이 필요함을 표시한다.
3. 사용자에게 그룹 재검증 여부를 확인하고 동의한 경우 새 기준으로 재검증한다. 보류하면 기존 판정을 새 기준에서도 유효한 결과처럼 표시하지 않는다.
4. 재검증 후 일관성 문제가 있는 이미지와 사유를 표시한다. 사용자가 재생성할 이미지를 선택하고 실행을 확인한다.
5. 선택 이미지의 새 생성 결과는 단일 검증 통과 후 새 그룹 기준과 일관성을 검사한다.

즉, 시스템 선정 → 사용자 기준 변경 → 그룹 재검증 확인 → 결과 확인 → 선택 이미지 재생성 확인 순서다. 기준 변경 자체로 재검증·재생성을 자동 실행하지 않는다. 선택 재생성은 ADR-0003의 수동 재생성 정책을 따르며 그에 따른 단일 검증 자동 재생성 설정과 묶음 검증의 자동 재생성은 구분한다.

## 후속 구체화

[ADR-0021](0021-core-domain-and-image-groups.md)에서 작품·캐릭터·의상 분류 아래 그룹마다 하나의 외형·의상 구성을 고정하도록 구체화했다. 같은 조합의 별도 그룹도 허용한다. 기존 그룹 추가는 고정 구성을 사용하고 수정된 구성은 새 그룹으로 생성한다. 이는 대표·보조 이미지 교체를 막지 않으며 본 ADR은 Accepted, supersede 관계 없음으로 유지한다.

[ADR-0008](0008-group-reference-selection.md)에서 대표 1장·보조 자료 선정, 비교 부족·충돌 처리, 새 이미지 추가·기준 삭제 처리를 확정했다. 이 ADR은 Accepted로 유지하며 기존 결정을 대체하지 않는다.

## 남은 결정

단일·묶음 요청/응답 Schema, 그룹 완료·부분 실패, 기준 선정의 구체 점수·알고리즘, 일관성 판단 불확실성, 비교 Context의 세부 구성·전송, 보조 이미지 변경/삭제 영향, 확인 요청 중 상태 변경·동시성은 미정이다. 기준 선정 품질을 보장하거나 묶음 자동 재생성 반복 정책을 확정하지 않는다.

[ADR-0009](0009-group-validation-results.md)에서 이미지별 결과·그룹 요약·기준 유효성·부분 오류 보존·확인 중 기준 변경 처리를 확정했다. 위 결과/집계 미정 범위는 필드명·기계 검증 Schema 등 상세 계약으로 한정한다.

[ADR-0010](0010-group-completion-and-partial-failure.md)에서 고정 생성 대상·묶음 시작 조건·부분 실패/취소 처리를 확정했다. 생성 현황과 일관성 요약을 분리하며 전체 일치는 실제 비교 대상에 한정한다. 위 그룹 완료·부분 실패 미정 표현은 구체 상태/접수/동시성 계약으로 한정한다.

## 충돌 및 대체 확인

ADR-0001~0006을 확인했다. Core 책임·단일 Prompt 판정·재생성 횟수·오류 후 자동 실행 금지를 유지한다. ADR-0005는 Proposed로 유지하며 단일 이미지 응답 초안을 묶음 응답으로 확정하지 않는다. 기존 문서의 중복 검사는 후보였으므로 이번 범위 제외가 Accepted ADR을 대체하지 않는다. 기존 ADR 상태와 supersede 관계는 변경하지 않는다.
