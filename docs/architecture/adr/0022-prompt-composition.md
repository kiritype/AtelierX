# ADR-0022: 전역·의상 Prompt 조합

> 2026-09-23: [ADR-0026](0026-fragment-numbers-output-names-hands.md)로 일부 변경되었다. 해당 부분은 그 ADR을 따른다.

2026-09-13 최신 사용자 정정: 조각 기반 제작에서는 **외형을 항상 포함**한다. 전역 공유 조각은 본문과 **상의·하의 포함 여부만** 저장하며 appearance 선택 필드는 두지 않는다. 아래 과거 조각별 외형 선택 설명을 대체한다. 전역 Positive + 외형 + 선택한 상의/하의 + 조각 본문, 전역 Negative + 캐릭터 Negative를 사용한다. 구현·테스트를 계속 진행하도록 승인됐다.


2026-09-13 최신 사용자 확정으로 후속 조각 기반 제작은 **전역 Positive + 조각별 포함 대상으로 지정한 의상 외형·상의·하의 + 사용자 조각 본문**으로 조합한다. 조각은 작품/캐릭터/의상과 독립된 전역 공유 데이터이며, 각 조각에 세 영역 포함 여부를 둔다. 구도·표정·동작·상황은 조각 본문으로 통합하고 별도 공통 Prompt는 추가하지 않는다. Negative는 기존 전역 + 캐릭터를 유지한다. 아래 개별 입력 기반 구현 설명은 현재 코드 이력이며 후속 설계는 이 결정이 우선한다. Accepted 상태와 기존 출처·검증 원칙은 유지하며 조각 API는 아직 미구현이다. [최신 flow](../../modules/core-generation.md).

2026-09-13 후속 사용자 지시: 제작의 구도는 제한된 preset 대신 자유 Prompt 조합으로 입력하며, 구도·표정·자세/동작·상황은 여러 줄을 허용한다. `upper body, white background, simple background`처럼 배경도 조합 가능하다. 구현의 기존 upper_body/full_body 값은 호환을 위해 유지하고 custom 입력을 추가한다. custom의 영역 포함은 명시 bool이며 Core가 확인 가능한 충돌을 거절한다. 여러 줄을 별도 이미지 후보로 자동 전개하지 않는 것은 초기 구현 해석이며, 대량 조각 조합은 [별도 사전 검토](../../modules/core-generation.md)다. 기존 Prompt 출처·검증·순서 원칙 및 Accepted 상태는 유지한다.

2026-09-13 [ADR-0023](0023-negative-prompt-sources.md)으로 Negative를 전역 → 캐릭터 순으로 합성하고 출처를 고정하도록 부분 변경했다. 의상별 Negative는 추가하지 않는다. 아래 이전 설명보다 우선하며 Accepted 상태는 유지한다.

- 상태: Accepted
- 작성일 / 확정일: 2026-09-13
- Supersedes / Superseded by: 없음
- 관련: [ADR-0021](0021-core-domain-and-image-groups.md), [ADR-0003](0003-generation-execution-and-queue.md), [ADR-0004](0004-validation-outcomes-and-errors.md), [ADR-0017](0017-regeneration-change-validation.md); 요구사항 C-04~C-08, C-14

## 배경

작품 > 캐릭터 > 의상(외형 포함)은 편집·저장 category다. 전역 Positive(퀄리티)·Negative와 의상 내부 외형 / 상의 / 하의(풋웨어 포함)의 실제 문구를 Core가 조합하는 규칙을 정한다. 사용자가 직전 권고안을 승인했으며 Backend 구현 지시는 아니다.

## 결정

| 항목 | 확정 규칙 |
| --- | --- |
| Positive | 전역 퀄리티 → 외형 → 상의 → 하의 → 선택한 구도·표정·동작·상황 순서로 조합한다. 구도에 따라 제외한 항목은 넣지 않는다. |
| Negative | 전역 Negative를 기본으로 사용한다. 초기에는 의상별 Negative 저장 항목을 추가하지 않는다. |
| 분류명 | 작품·캐릭터·의상 이름을 자동 삽입하지 않고 저장된 Prompt 본문만 사용한다. |
| 내용 보존 | 일반 조합에서 사용자가 작성한 문구·가중치를 유지한다. AI 재작성·번역·유사 문구 삭제를 자동 수행하지 않는다. |
| 충돌 | 뒤쪽 문구가 앞쪽 내용을 자동으로 덮어쓰지 않는다. 확인 가능한 모순은 생성 전에 안내하고 수정하도록 한다. |
| 확인·기록 | Core가 최종 Positive/Negative를 제공해 생성 전에 확인할 수 있게 한다. 제출된 최종 문구는 해당 생성 시도에 고정해 보존한다. |

상반신 예시는 전역 퀄리티 + 외형 + 상의 + 구도·표정·동작·상황이다. 하의에 저장된 풋웨어·체인 묘사도 함께 제외한다.

## 대안과 영향

분류 계층의 이름을 그대로 생성 문구에 삽입하는 방식은 사용자 정정에 따라 채택하지 않는다. 후순위 자동 덮어쓰기나 유사 문구 자동 제거 대신 작성 내용을 보존한다. 조합 순서는 모델의 의미적 우선순위를 보장하지 않으며 자유 문장의 모든 모순을 탐지한다고 보장하지 않는다.

Core가 조합과 최종 문구 제공을 담당하고 Frontend·CLI는 이를 표시·제출한다. 생성 전 확인 기능은 모든 요청에 별도 승인 단계를 강제한다는 뜻이 아니다. Generation은 고정 입력을 실행하고 Validation은 실제 생성 문구를 기준으로 검사한다.

## 남은 결정

표정·동작·상황 Prompt 저장과 복수 선택 조합, 일반 생성 요청의 추가 문구·Negative 덮어쓰기 범위, 구분자·지원 가중치 문법·모델별 표현, 충돌 탐지 상세, 얼굴 클로즈업·원피스 등 세부 구도 사례, Prompt 편집 버전·복원 방식은 미정이다. 시도별 문구 보존을 전체 버전 관리 계약의 승인으로 간주하지 않는다.

## 충돌 및 대체 확인

ADR-0021의 category·의상 3구분과 그룹 고정, ADR-0003의 Core 책임·고정 입력, ADR-0004의 upper body 제외 및 실제 Prompt 검증과 일치한다. 일반 조합의 자동 재작성 금지는 ADR-0017에 따라 Validation이 제작 의도를 보존하며 해당 재생성 시도에 제안하는 변경을 금지하지 않는다. 원본 Prompt·Preset·그룹 구성을 변경하지 않는 원칙은 유지한다. 기존 Accepted 상태 및 supersede 관계는 변경하지 않는다.

## 2026-09-22 사용자 확정 정정 — 외형 소유권·액세서리

작품 > 캐릭터 > 의상 계층은 유지하며 캐릭터에 외형을, 의상에 상의·하의·액세서리를 저장한다. 이 결정은 이 문서의 과거 의상 내부 외형 배치에 한해 대체한다. Positive는 전역 퀄리티 + 캐릭터 외형(항상) + 조각에서 선택한 상의/하의/액세서리 + 조각 본문 순서다. 액세서리 포함 기본값은 true다. 전역·캐릭터 Negative 책임은 ADR-0023을 유지한다.

이전 데이터의 외형이 의상마다 다르면 자동으로 한 값을 고르지 않는다. 동일 값의 안전 이전과 명시적 충돌 해소를 구분하며 기존 revision·고정 그룹·Task/계획 스냅샷은 수정하지 않는다. 사용자 승인된 제품 변경이며 상세 API/호환성은 구현 명세에 기록한다.
