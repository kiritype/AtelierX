# ADR-0013: 검증 이미지 접근·업로드 제한·임시 파일 관리

- 상태: Accepted
- 작성일 / 확정일: 2026-09-13
- Supersedes / Superseded by: 없음
- 관련: [ADR-0012](0012-validation-image-transfer-and-required-input.md), [ADR-0006](0006-validation-manual-retry.md)

## 결정

| 항목 | 확정 원칙 |
| --- | --- |
| 접근 권한 | 설정된 Generation 서버에서 해당 요청의 이미지만 조회. 로컬·분산 모두 서비스 인증 사용 |
| 접근 유효기간 | 대기·실행 중 조회 가능하게 유지하며 재검증 요청에서는 권한 재확인 |
| 업로드 제한 | 파일 용량·Decode 후 픽셀 수·요청당 이미지 수 각각 제한 |
| 한도 초과 | AI 호출 전에 오류 반환. 임의 축소·압축하지 않음 |
| 임시 파일 소유 | 업로드를 받은 Validation이 관리 |
| 처리 중 파일 | 대기·실행 중 사용하는 파일은 삭제하지 않음 |
| 완료 후 정리 | 성공·실패·취소 후 일정 기간 보관한 다음 삭제 |
| 재검증 입력 | 보관 중이면 기존 업로드 사용, 정리됐으면 재업로드 안내 |
| 이력과 원본 | 임시 파일 삭제 시 검증 이력은 유지. Generation 원본은 임시 정리 대상에서 제외 |

지원 미디어는 ADR-0012의 정지 PNG·WebP로 유지한다. 업로드 보관이 이미지의 Core 자동 등록이나 영구 보관을 의미하지 않는다. 계속 보관할 이미지의 등록·저장 절차는 후속 계약이다.

접근 가능 기간을 유지한다는 원칙은 인증을 생략하거나 만료 없는 공개 URL을 제공한다는 뜻이 아니다. 인증 방식·갱신·회수 등의 기술 계약은 후속 결정한다. 실행 중인 파일을 보호하면서 종료된 요청의 파일을 정리하는 구체 저장·경쟁 처리 역시 별도 설계한다.

## 미결정 사항

서비스 인증 기술·Secret 관리·접근 기간 수치·갱신 방식, 파일 용량/픽셀/이미지 수 제한값과 설정 위치, 임시 보관 기간·정리 주기·디스크 부족 대응, 삭제 실패·재시작 복구·동시 참조 처리, 영구 등록·보관 절차는 미정이다.

## 충돌 및 대체 확인

ADR-0001~0012의 REST·파일 소유·오류 분리·수동 재검증과 대조했다. ADR-0012의 미정 접근/보관 원칙을 구체화하고 기존 Accepted 결정을 대체하지 않는다. 단일·묶음 비교 결과를 임시 파일과 함께 삭제하지 않으며, 검증 오류의 자동 이미지 재생성 금지를 유지한다. ADR-0005 전체 응답 Schema는 Proposed다.
