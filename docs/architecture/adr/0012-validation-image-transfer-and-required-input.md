# ADR-0012: 검증 이미지 전달·필수 정보·입력 부족 처리

- 상태: Accepted
- 작성일 / 확정일: 2026-09-13
- Supersedes / Superseded by: 없음
- 관련: [ADR-0011](0011-validation-input-context.md), [ADR-0004](0004-validation-outcomes-and-errors.md), [ADR-0005 초안](0005-validation-response-contract.md), [ADR-0008](0008-group-reference-selection.md)

## 결정

| 항목 | 확정 기준 |
| --- | --- |
| 서비스 간 이미지 전달 | Generation이 이미지 조회 API를 제공하고 Validation이 필요한 이미지를 가져옴 |
| 로컬·분산 배치 | 같은 PC에서도 동일 API 계약 사용. 공유 폴더·다른 PC의 로컬 경로 접근을 필수로 두지 않음 |
| 직접 검증 요청 | 등록되지 않은 이미지도 업로드 가능. 단일 검증에는 실제 생성 Prompt 필요 |
| 이미지 고정성 | 요청이 특정 파일을 가리키도록 식별·무결성 정보 연결. 검증 도중 다른 파일로 바뀌면 오류 |
| 접근 실패 | 파일 없음·접근 거부·전송 실패는 입력 접근 오류. 이미지 불합격으로 처리하지 않음 |
| 단일 필수 정보 | 이미지·실제 Positive Prompt·수행할 검사 설정 |
| Negative Prompt | 실제 생성에서 사용했다면 전달, 사용하지 않았다면 빈 값임을 명시 |
| 생성·후처리 설정 | 출력 조건 검사나 재생성 변경값 제안에 필요한 항목 전달 |
| 묶음 필수 정보 | 그룹 식별·판정 대상 목록·대표 기준·기준 식별 정보·대상별 Prompt·유지할 외형/의상 정보 |
| 보조 이미지 | 기본 선택 정보. 대표만으로 비교할 수 없는 특징이 있으면 필요 |
| 필수 정보 누락 | AI 호출 전에 입력 오류 반환. 누락을 AI가 추측해 채우지 않음 |
| 선택 정보 부족 | 해당 검사·변경값 제안에 미치는 영향을 명시. 수행하지 않은 검사를 통과로 표시하지 않음 |

## 정보 부족의 구분

- 검증 자체에 필요한 정보가 부족하면 요청 오류로 처리한다.
- 이미지·Prompt로 검증은 가능하지만 재생성 설정 제안에 필요한 정보가 부족하면 판정은 제공하되 자동 재생성 제안은 하지 않고 이유를 표시한다.
- 입력은 정상이나 기준 이미지에서 특징이 보이지 않으면 입력 누락 오류가 아니라 ADR-0008의 묶음 비교 불충분으로 처리한다.

접근 권한은 요청 수행에 필요한 파일로 제한한다. 내부 API의 이미지 식별·접근 정보와 외부 AI로 보내는 실제 검사 Context는 ADR-0011대로 구분한다. 미등록 업로드 허용은 Prompt 없는 단일 검증을 허용하거나 Core에 이미지를 자동 등록하는 결정이 아니다.

## 입력 미디어 범위 — 2026-09-13 추가 확정

초기 Validation은 정지 이미지만 지원한다. 애니메이션·동영상·다중 프레임 입력은 제외한다. 묶음 검증은 여러 정지 이미지를 비교하는 기능이므로 계속 지원한다. 미지원 입력에서 임의로 첫 프레임을 뽑아 검증하는 방식은 지원 범위에 포함하지 않는다.

2026-09-13 후속 확정: 지원 형식은 **정지 PNG·WebP**로 한정한다. JPEG 및 다른 형식은 초기 범위에서 제외한다. 확장자만으로 허용하지 않고 실제 형식·정지 이미지 여부를 확인하는 세부 방식은 구현 시 정한다. 서비스 인증·접근 유효기간·업로드 한도·임시 보관 정책은 이번 확인으로 일괄 승인하지 않는다.

## 미결정 사항

Endpoint·업로드 형식·인증 방식·접근 유효기간·크기 제한, 파일 식별/무결성 알고리즘과 검사 시점, 요청 Schema·정확한 코드/HTTP 매핑·임시 업로드 수명·접수 원자성은 후속 설계한다. Generation 조회 API 외 임의 외부 URL 접근을 이번에 허용하지 않는다.

[ADR-0013](0013-validation-access-and-temporary-files.md)에서 서비스 인증·접근 유지/재확인·업로드 제한·임시 보관/정리 원칙을 후속 확정했다. 위 접근/보관 미정 표현은 기술 방식·수치·동시성 등 상세로 한정한다.

## 충돌 및 대체 확인

ADR-0001~0011의 REST·Core DB 소유·Generation 파일 보관·실제 Prompt 입력·오류 후 자동 재생성 금지를 유지한다. ADR-0011의 미정 전달/입력 부족 정책을 구체화하며 Accepted 결정을 대체하지 않는다. ADR-0005는 Proposed다. 해당 초안의 변경값 생성 실패 오류는 제공된 정보가 충분한데 Provider 응답이 잘못된 경우와 이번 입력 정보 부족을 구분해 후속 Schema에서 정리한다.
