# ADR-0017: 재생성 변경값 범위·검사·적용

> 2026-09-23: [ADR-0025](0025-validation-check-scope.md)로 일부 변경되었다. 해당 부분은 그 ADR을 따른다.

- 상태: Accepted
- 작성일 / 확정일: 2026-09-13
- Supersedes / Superseded by: 없음
- 관련: [ADR-0003](0003-generation-execution-and-queue.md), [ADR-0005 초안](0005-validation-response-contract.md), [ADR-0012](0012-validation-image-transfer-and-required-input.md)

## 결정

| 항목 | 확정 기준 |
| --- | --- |
| 변경 대상 | 해당 생성 방식이 지원하는 Prompt·Seed·CFG·Steps·Sampler·Scheduler·모델·LoRA·VAE·해상도·후처리 설정 |
| 변경 제외 | 작품·캐릭터 원본 정보, 저장된 Prompt·Preset, 파일 경로·접근 권한·재생성 상한 |
| 적용 범위 | 다음 생성 시도 입력에만 적용. 기존 이미지·입력·검증 기록 보존 |
| 근거 | 변경 필드마다 불합격 사유와 연결된 이유 제공 |
| 최소 변경 | 문제와 관련된 설정만 변경. 변경 개수의 고정 상한 없음 |
| Prompt | 의도한 특징이 잘 생성되도록 표현 보완. 불합격 요소 삭제·다른 특징으로 교체하여 검사 회피 금지 |
| Seed | 다른 결과를 시도하는 수단으로 허용. 모든 불합격에 Seed만 변경하는 규칙 없음 |
| 값 검사 | 타입·허용 범위·지원 여부 검사. 범위 밖 값을 임의 보정하지 않음 |
| 모델 조합 | 모델·Text Encoder·VAE·LoRA·Sampler 등의 호환성 확인. 모델 변경 시 필요한 관련 설정 함께 제안 |
| 설치 | 사용 가능한 모델·LoRA만 선택. 자동 다운로드·설치 없음 |
| 제안 적용 | 여러 변경을 하나의 제안으로 검사하고 모두 유효할 때 적용. 유효한 일부만 적용하지 않음 |
| 잘못된 제안 | 자동 재생성하지 않고 변경값 오류·사유 반환 |
| 정보 부족 | 검증 가능하면 판정 제공. 유효한 변경 제안에 필요한 정보가 부족하면 자동 제안 없이 사유 표시 |
| 사용자 확인 | 자동 On이면 유효한 제안을 상한 내 적용. Off이면 제안만 표시하고 사용자 선택 대기 |

여러 변경의 일괄 적용은 한 제안의 원자적 입력 구성을 뜻하며, 묶음 이미지 검증 후 자동 재생성을 허용하는 의미가 아니다. ADR-0007의 선택 재생성 확인과 오류 후 자동 실행 금지는 유지한다. Off에서 사용자 선택 대기는 ADR-0010의 기존 그룹 처리를 무기한 대기시키는 실행 상태가 아니다.

## 책임

- Validation: 불합격 분석·변경값 제안·제안 형식 검사.
- Core: 기존 생성 입력과 합쳐 다음 시도 구성·자동 설정/상한 확인.
- Generation: 실제 실행 환경의 설정·모델 조합 최종 검사. 부적합하면 실행 전 오류 반환.

예: 파란 눈을 요청했는데 갈색 눈이 나오면 파란 눈이 반영되도록 표현·생성 설정을 보완한다. Prompt를 갈색 눈으로 바꿔 합격시키지 않는다. 모든 생성 설정의 변경 허용은 사용자의 제작 의도 변경 권한이 아니다.

## 미결정 사항

허용 필드의 기계 검증 Schema·중첩 표현·모델별 범위/호환성 정보, 사용 가능한 모델 목록 전달 방식, 의도 보존·최소 변경의 실제 검사, 변경값 오류 코드/HTTP, 접수와 실제 실행 사이 환경 변경·경쟁 처리는 후속 설계한다. Generation 오류별 복구 전체 정책을 이번 입력 검사로 확정하지 않는다.

## 충돌 및 대체 확인

ADR-0001~0016의 Core 원본 소유·고정 시도 입력·최소 변경·상한·오류 분리와 대조했다. 기존 원칙을 구체화하며 Accepted 결정을 대체하지 않는다. ADR-0005는 Proposed로 유지하고 ADR-0012의 정보 부족과 잘못된 Provider 변경값을 구분한다.
