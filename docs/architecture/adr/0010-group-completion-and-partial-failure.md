# ADR-0010: 묶음 검증 시작과 그룹 부분 실패·취소

- 상태: Accepted
- 작성일 / 확정일: 2026-09-13
- Supersedes / Superseded by: 없음
- 관련: [ADR-0003](0003-generation-execution-and-queue.md), [ADR-0007](0007-group-image-validation.md), [ADR-0008](0008-group-reference-selection.md), [ADR-0009](0009-group-validation-results.md)

## 결정 범위

그룹의 생성 대상·묶음 검증 시작 시점·일부 실패와 취소 처리를 정한다. 생성 현황과 일관성 결과를 구분하고 비교 범위를 표시한다. 구체 Job 상태명·접수 및 동시성 Schema는 후속 정의한다.

## 결정

| 항목 | 확정 기준 |
| --- | --- |
| 생성 대상 | 생성 요청 시 대상 목록을 고정. 이후 추가 요청은 기존 목록과 구분 |
| 묶음 검증 시작 | 모든 대상의 생성·단일 검증·허용된 자동 재생성이 완료되거나 실패·취소·상한 도달로 종료된 뒤 |
| 비교 이미지 | 각 대상의 최종 단일 검증 통과 이미지. 재생성 과정의 이전 이미지는 이력으로 보존 |
| 일부 대상 실패 | 단일 검증 통과 이미지가 2장 이상이면 그 이미지들로 묶음 검증 진행 |
| 제외 사유 | 생성 실패·단일 검증 오류·불합격 종료·취소를 구분해 비교 제외 이유 표시 |
| 전체 작업 취소 | 진행 중 작업에 중단 요청, 후속 묶음 검증 시작 금지. 완료 결과 보존 |
| 개별 대상 취소 | 해당 대상만 종료하고 나머지 처리 계속 |
| 수동 동작 대기 | 사용자 수동 재검증·재생성을 기다리느라 기존 그룹 처리를 무기한 대기시키지 않음. 나중에 결과가 추가되면 현재 기준으로 해당 이미지 검사 |
| 통과 이미지 0장 | 묶음 검증 대기, 비교 가능한 이미지가 없다는 사유 표시 |
| 통과 이미지 1장 | 묶음 검증 미실행, 비교 대상 부족 표시 |
| 종료 그룹에 새 결과 추가 | 기존 기준을 유지하고 추가 이미지의 단일 검증·일관성 검사 결과 반영 |

Core가 고정 대상 목록과 대상별 종료 상태·이력을 관리하고 묶음 검증 요청을 조정한다. Validation은 전달받은 통과 이미지와 기준을 검사한다. 대상 목록 고정은 그룹에 이후 이미지를 추가하지 못하게 하는 제약이 아니라 기존 요청의 완료 조건이 계속 바뀌지 않게 하는 경계다.

통과 이미지 0장으로 묶음 검증이 대기하는 상태와 생성 요청의 처리가 종료된 상태는 구분한다. 사용자 입력을 기다리기 위해 완료된 생성 작업을 계속 실행 중으로 유지하지 않는다. 기준이 아직 없는 그룹에 이미지가 추가되면 ADR-0008의 기준 선정 절차를 적용한다. 기준 교체가 필요한 경우 ADR-0007의 사용자 확인을 유지한다.

## 생성 현황과 일관성 요약 분리

그룹 생성의 완료·실패·취소 현황과 ADR-0009의 일관성 요약을 별도로 표시한다. 일관성 요약에는 실제 비교 범위와 비교에서 제외된 대상을 함께 제공한다.

예: 요청 10장 중 8장은 생성·단일 검증 통과, 2장은 생성 실패하고 비교한 8장이 모두 일치한 경우:

- 생성 현황: 성공 8 / 실패 2.
- 일관성 현황: 비교한 8장 모두 일치.
- 그룹 표시: **일부 생성 실패 · 통과 이미지 간 전체 일치**.

ADR-0009의 전체 일치는 현재 기준의 일관성 비교 대상 전체에 대한 뜻이다. 요청한 모든 이미지가 생성·단일 검증까지 성공했다는 뜻으로 표시하지 않는다. 비교 대상 안에 미검증·비교 불충분·실행 오류가 남으면 기존 판정 미완료 규칙을 유지한다. 생성 단계에서 제외된 대상은 생성 현황과 제외 사유로 구분한다.

## 영향과 미결정 사항

일부 생성 실패가 성공 이미지의 묶음 검증을 막지 않으며, 실패·취소·이전 시도는 이력에서 추적할 수 있다. 전체 작업 취소는 후속 자동 흐름을 중지하고 이미 완료된 결과를 삭제하지 않는다.

대상·그룹·시도 ID 및 접수 Schema, 최종 통과 결과 선택의 저장 계약, 동시에 들어온 수동 요청·추가·삭제의 처리, 실행 중 묶음 검증 취소의 상세 상태·응답, 시작 조건 충족과 취소 요청의 경쟁, 이벤트·복구·중복 방지는 미정이다. 단일·묶음 검증 입력 계약에서 다음으로 검토한다.

[ADR-0011](0011-validation-input-context.md)에서 검증 입력 정보의 의미·최종 이미지·Core 준비 책임을 확정했다. 구체 필드명·필수/선택·전송 방식·동시성은 계속 미정이다.

## 충돌 및 대체 확인

ADR-0001~0009를 대조했다. ADR-0003의 취소·자동 재생성 종료, ADR-0007의 통과 이미지 비교, ADR-0008의 0/1장 처리, ADR-0009의 그룹 요약을 유지한다. 기존 전체 일치의 비교 범위를 구체화하며 Accepted 결정을 대체하지 않는다. ADR-0005 응답 구조는 계속 Proposed다.
