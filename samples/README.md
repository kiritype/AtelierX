# 샘플 작품

앱에 함께 들어가는 샘플 작품이다. 작품 선택 화면의 "샘플 작품"에서 고르면 **복사본**이 새 작품으로 만들어진다
([docs/features/01-works.md](../docs/features/01-works.md)). 배포 묶음에서는 `app/samples/`에 들어간다.

모든 내용은 샘플용으로 새로 만든 가상 작품이다.

| 폴더 | 규모 | 보여 주는 것 |
|---|---|---|
| [single/](single/) | 주인공 한 명 | 메인 프롬프트, 시작 상황, 캐릭터 섹션(식별·외모·의상 두 벌), 장소 로어북, 메모, 이미지 디자인 |
| [ensemble/](ensemble/) | 고정 인물 여럿 | 캐릭터 세 명과 관계도(방향별 호칭), 로어북 없는 인물(`N01`), 용어집 |
| [simulation/](simulation/) | 시스템 중심 | 항상 넣기 규칙 항목, 장소별 로어북, JSX 상태창과 예시 props, 메인 프롬프트 속 상태창 문구 |

## 폴더 구성

각 샘플은 실제 작품 폴더와 같다. 사용자 트리(`.md`, `.jsx`)와 앱 데이터(`.atelierx/`)로 나뉜다
([docs/data-model.md](../docs/data-model.md#작품-폴더)).

- 폴더 구성은 권장 예시일 뿐이다. 앱은 폴더 이름을 보지 않고 각 파일의 `kind`로 종류를 정한다.
- 이미지 디자인의 `source.hash`는 `"sample"`로 두었다. 샘플을 설치할 때 앱이 지금 본문으로 다시 계산해 "최신"으로 맞춘다.
- 작품 ID(`W001`~`W003`)는 설치할 때 다음 번호로 바뀐다.
