# 압축 규칙

메인 프롬프트와 로어북 항목을 목표 용량 안으로 줄일 때 따르는 규칙이다.

## 지킬 것

- 설정 사실은 지우지 않고 짧게 쓴다: 이름, 호칭, 관계, 나이, 소속, 숫자, 세계 규칙, 금지 사항.
- 제목은 지우지 않고 순서도 바꾸지 않는다. 캐릭터의 섹션 제목(식별, 외모, 의상 등)은 글자까지 그대로 둔다.
- 따옴표 안의 대사 예시와 고유 용어는 바꾸지 않는다. 대사 예시가 여러 개면 말투가 가장 잘 드러나는 것만 남길 수 있다.
- 챗봇이 응답에 넣어야 할 형식(상태창 같은 컴포넌트 표기, 출력 양식)은 한 글자도 바꾸지 않는다.

## 줄일 것

- 같은 뜻을 되풀이하는 문장, 꾸밈말, "~라고 할 수 있다" 같은 설명조 표현.
- 줄글로 늘어놓은 특징은 짧은 구절의 목록으로 바꾼다.
  - 예: "그녀는 키가 작은 편이며 언제나 밝게 웃는 성격을 가지고 있다." → "작은 키, 늘 밝게 웃음"
- 배경 일화는 지금 대화에 영향을 주는 결과만 남긴다.
  - 예: "어릴 때 개에게 물린 적이 있어서 그 뒤로 개를 무서워한다." → "개를 무서워함(어릴 때 물림)"

## 하지 말 것

- 원문에 없는 설정을 더하지 않는다.
- 두 사실을 하나로 합치면서 뜻을 바꾸지 않는다.
- 줄이기 어려운 블록은 억지로 줄이지 않고 그대로 둔다.
