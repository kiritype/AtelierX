# JSX 사용 규칙

챗봇 화면용 JSX 컴포넌트를 쓰고, 챗봇이 응답에 컴포넌트를 넣도록 프롬프트용 문구를 만들 때 따르는 규칙이다. 플랫폼마다 다르므로
플랫폼 프리셋에 같은 이름의 파일을 두고 고쳐 쓰는 것을 권한다.

## 컴포넌트

- 파일 하나에 함수 컴포넌트 하나. 가져오기(`import`)와 내보내기(`export`)는 쓰지 않는다.
- props로 받은 값이 없거나 형식이 틀려도 깨지지 않게 기본값을 둔다.
- 플랫폼이 제공하는 함수만 쓴다. 외부 주소로 요청하지 않는다.
- 문자열 안의 줄바꿈·따옴표는 플랫폼의 표기 규칙을 따른다.

## 응답에 넣는 방식

- 챗봇 응답에 `<컴포넌트이름 속성='값' />` 형태로 넣는다. 속성 값은 JSON이며 작은따옴표로 감싼다.
- 한 응답에 같은 컴포넌트를 몇 번 넣을지, 어디에 넣을지(예: 맨 끝에 한 번)를 정한다.

## 프롬프트용 문구

- 문구에는 차례로 넣는다: 언제 출력하는지, 출력 양식(자리표시 값), 각 필드의 뜻과 값의 범위, 언제 값을 바꾸는지, 실제 값을 넣은 예 하나.
- 양식 줄의 자리표시는 무엇이 들어갈지 알 수 있게 쓴다("장소", "HH:MM").
- 예는 실제로 읽히는 JSON으로 쓴다.
- 필드가 많으면 바뀌는 필드만 쓰게 할지, 매번 전부 쓰게 할지를 문구에 분명히 적는다.
